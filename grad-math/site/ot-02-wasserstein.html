最优传输 II · Wasserstein 几何与 Brenier 定理

对标：Santambrogio §1.3、§5–7 / Villani Topics 入门章 ｜ 前置：ot-01、cvx-01、概率 V 平方成本 \(c = \|x-y\|^2\) 的世界格外美好：在源测度绝对连续等条件下，Brenier 定理说最优映射是凸函数的梯度（高维的"单调重排"）；\(W_2\) 让概率分布全体成为一个几何空间——有距离、有测地线、有重心，"分布的插值与平均"从此有正确定义。

学习层：先让分位数走，再谈分布的测地线

1. 具体谜题：同一批质量，究竟走哪一条“直线”？

取两个一维离散分布

\[ \mu_0=\delta_0,\qquad \mu_1=0.35\,\delta_{-2}+0.65\,\delta_{2}. \]

先不看公式，写下三个预测：

  • 若把 \(\mu_0\) 的质量允许拆分，最优耦合会有几条正质量边？它们各自承载多少质量？
  • \(t=\frac12\) 时，McCann 位移插值会出现一个原子还是两个原子？混合插值 \((1-t)\mu_0+t\mu_1\) 呢？
  • 若 \(D=W_2(\mu_0,\mu_1)\)，你预计 \(W_2(\mu_0,\mu_t)=tD\) 与 \(W_2(\mu_t,\mu_1)=(1-t)D\) 是否成立？

把答案先写成可检验的数值：这里 \(D=\sqrt{0.35\cdot 2^2+0.65\cdot 2^2}=2\)；位移插值在 \(t=\frac12\) 的位置应为 \(-1\)、\(1\)，质量为 \(0.35\)、\(0.65\)，而混合插值仍保留 \(0\)、\(-2\)、\(2\) 三个位置。打开实验后只核对预测，不把动画直觉当作证明。

2. 透明的一维离散模型：共同分位数就是耦合

把每个原子 \((x_i,a_i)\) 按位置排序，令

\[ I_i=[A_{i-1},A_i),\qquad A_i=\sum_{k\le i}a_k, \]

则分位数函数 \(Q_\mu(u)=x_i\)（\(u\in I_i\)）。对 \(\mu_0\) 与 \(\mu_1\) 使用同一个 \(u\in[0,1]\)，得到耦合

\[ \pi_Q=(Q_{\mu_0},Q_{\mu_1})_\#\mathrm{Unif}[0,1], \qquad W_2^2(\mu_0,\mu_1)=\int_0^1|Q_{\mu_0}(u)-Q_{\mu_1}(u)|^2\,du. \]

有限表中，每个两个区间的重叠长度就是一条运输边的质量：

\[ \pi_{ij}=|I_i\cap J_j|. \]

例如上面的 \(I=[0,1)\)、\(J_1=[0,0.35)\)、\(J_2=[0.35,1)\)，所以 \(\pi_{1,1}=0.35\)、\(\pi_{1,2}=0.65\)。这不是抽样近似，也不是把质量偷偷复制；它正好满足行和列边缘。若多个源区间落入同一个目标区间，就是质量汇合；一个源区间与多个目标区间相交，就是质量拆分。

在这个耦合上定义

\[ X_t=(1-t)Q_{\mu_0}(U)+tQ_{\mu_1}(U), \qquad \mu_t=\mathcal L(X_t). \]

每个 \(u\) 的速度 \(Q_{\mu_1}(u)-Q_{\mu_0}(u)\) 不随 \(t\) 变化，且

\[ W_2(\mu_s,\mu_t)=|t-s|W_2(\mu_0,\mu_1). \]

这条等式解释“匀速”：它是耦合下的二次平均速度恒定，不是说每个时刻的密度都光滑，也不是说原子会自动变成密度。

3. 形式化：从离散耦合到 Wasserstein 测地线

记

\[ \mathcal P_2(\mathbb R^d)=\left\{\mu:\int\|x\|^2\,d\mu(x)<\infty\right\}, \]

并定义

\[ W_2^2(\mu,\nu)=\inf_{\pi\in\Pi(\mu,\nu)} \int\|x-y\|^2\,d\pi(x,y). \]

若 \(\pi^*\) 是任一最优耦合，则

\[ \mu_t=((1-t)x+ty)_\#\pi^*,\qquad 0\le t\le1, \]

是一条 \(W_2\) 测地线，并满足上面的匀速恒等式。只有在确实存在最优映射 \(T\) 时，才可把它写成 \(\mu_t=((1-t)\mathrm{id}+tT)_\#\mu_0\)。一维凸成本时共同分位数给出这条最优耦合；高维一般不能把“排序”或 Brenier map 当作无条件存在的黑箱。

线性混合

\[ \widetilde\mu_t=(1-t)\mu_0+t\mu_1 \]

是在概率测度的向量空间里取平均，而不是沿 \(W_2\) 的最短路。它保留两个端点的质量标签，因此会产生“淡入淡出”的鬼影；位移插值保留的是耦合粒子的运动。

4. 边界清单：四个容易说错的句子

情形 正确读法 实验中的检查
质量拆分 原子分布通常没有把每个源原子整体送往一个目标原子的 Monge 映射；Kantorovich 耦合仍然存在 看共同分位数区间的重叠表
\(t=0,1\) \(\mu_0\)、\(\mu_1\) 必须原样恢复；不能因合并同位置原子而丢质量 端点按钮与质量和
\(\mu_0=\mu_1\) \(W_2=0\)，最短路是常值；速度公式不应除以 \(W_2\) “相同分布”预设
原子边界 \(Q_\mu\) 是阶梯函数，\(\mu_t\) 可有原子、拆分和汇合；这不违反测地线定义 “原子边界”预设

此外，\(W_2\) 的唯一性也要分层说：最优耦合可能不唯一；若 \(\mu_0\) 绝对连续且成本为平方欧氏距离，Brenier 定理给出 \(\mu_0\)-几乎处处唯一的最优映射，因此由它生成的位移路径唯一。没有绝对连续性时，不应声称“高维总有一个 Brenier map”。

5. 互动实验：把三种账本放在同一屏

实验使用原生 JS/SVG，不抽样、不依赖外部库；滑块、按钮和选择框均保留触控尺寸，窄屏时控件与指标会响应式收束。可选五个确定性预设：

  1. 质量拆分：一处供给分到两处需求，直接看出映射与耦合的区别；
  2. 平移三峰：所有共同分位数位移相同，位移路径是形状平移；
  3. 质量汇合：多个源原子抵达同一目标原子；
  4. 相同分布：\(W_2=0\) 的退化边界；
  5. 原子边界：不等权原子同时拆分与汇合。

6. 迁移题：把一维直觉带到高维，但不要越界

  • 给出两个二维离散分布，先写一个耦合，再问它是否最优。哪些交换边会降低平方成本？若有多个最优耦合，生成的测地线是否可能不同？
  • 令 \(\mu_0\) 有密度、\(\mu_1\) 是有限原子分布。Brenier 映射在哪个方向成立？为什么“目标有原子”本身不妨碍从绝对连续源出发的映射，但反过来从一个原子源出发通常无法映到两个不同目标位置？
  • 对任意耦合 \(\pi\) 定义 \(\mu_t^\pi=((1-t)x+ty)_\#\pi\)，令 \(C(\pi)=\int\|x-y\|^2\,d\pi\)。用同一耦合证明 \(W_2(\mu_s^\pi,\mu_t^\pi)\le |s-t|\sqrt{C(\pi)}\)，从而曲线长度至多为 \(\sqrt{C(\pi)}\)；另一方面任何连接曲线的长度都至少是端点距离 \(W_2(\mu_0,\mu_1)\)。若这里的耦合取最优值 \(C(\pi)=W_2^2(\mu_0,\mu_1)\)，两界夹出常速测地线；不要把任意耦合都称为测地线。
  • 把平方成本换成 \(W_p\) 或换成一般代价后，哪些步骤仍然是耦合的推前，哪些步骤依赖一维分位数排序或二次欧氏结构？

1. Brenier 定理

定理（Brenier 1987） 设 \(\mu,\nu\in\mathcal P_2(\mathbb R^d)\)，且 \(\mu\) 对 Lebesgue 测度绝对连续；对成本 \(c(x,y)=\frac12\|x-y\|^2\)，存在 \(\mu\)-几乎处处定义的唯一最优传输映射，且它是某凸函数的梯度：

\[ T = \nabla\phi, \qquad \phi \text{ 凸}, \quad (\nabla\phi)_\#\mu = \nu \]

【骨架】 对偶（ot-01）的最优 \(\varphi\) 做 c-变换：平方成本下 \(c\)-凹性 ⟺ \(\phi(x) = \frac{\|x\|^2}{2} - \varphi(x)\) 凸（Legendre 语言，cvx-01）；对偶取等条件（Fenchel–Young！）逼出 \(y \in \partial\phi(x)\)；\(\mu\) 绝对连续时凸函数 a.e. 可微（凸分析【引用 Rademacher/Alexandrov】）⇒ \(\partial\phi\) a.e. 单点 = \(\nabla\phi\)：计划集中在映射图上——Kantorovich 解自动是 Monge 解。\(\blacksquare\)

读法："凸函数的梯度"= 一维单调映射的高维正名（一维凸函数导数单调增——ot-01 §3 的单调重排恰是特例）；唯一性与结构一步到位。这里的绝对连续性是源测度的条件，不是“所有高维分布都有 Brenier map”。在密度足够正规、映射可用经典 Hessian 表示时，\(T_\#\mu=\nu\) 的换元写开是 \(\det(\nabla^2\phi(x))\,\rho_\nu(\nabla\phi(x))=\rho_\mu(x)\)；一般情形要用 Aleksandrov/弱解语言，不能跳过正则性假设。它是完全非线性 PDE（正则性理论 = Caffarelli 的名作【引用】）：OT 与 PDE 的深水接口，知其坐标即可。

2. Wasserstein 空间的几何

\(W_2\) 是（二阶矩有限的）概率分布空间上的度量（三角不等式经"粘合引理"耦合拼接【骨架】）；且度量化弱收敛：\(W_2(\mu_n, \mu) \to 0 \iff \mu_n \xrightarrow{d} \mu\) + 二阶矩收敛【引用】——比 KL 温柔得多的拓扑（as-01 依分布收敛的度量化——统计与 OT 的接口）。

测地线（McCann 插值）：取任一最优耦合 \(\pi^*\in\Pi(\mu_0,\mu_1)\)，两分布间的"最短路径"为

\[ \mu_t = \big((1-t)x+ty\big)_\#\pi^* \]

若最优映射 \(T\) 存在，上式才可化为 \(\big((1-t)\mathrm{id}+tT\big)_\#\mu_0\)。——沿最优耦合的直线轨迹匀速搬运：粒子各自直线行进，且 \(W_2(\mu_s,\mu_t)=|s-t|W_2(\mu_0,\mu_1)\)。对比线性插值 \((1-t)\mu_0 + t\mu_1\)（两座山峰此消彼长——"鬼影"）：McCann 插值是质量沿耦合移动，但原子情形不保证每个中间时刻仍是单峰。"分布的正确动画"：形状插值、风格渐变、领域自适应的几何依据。

Wasserstein 重心：\(\min_\nu \sum\lambda_iW_2^2(\mu_i, \nu)\)——多个分布的"Fréchet 均值"：平均多张直方图/形状时保持形态（算术平均则糊成多峰）。

Otto 微积分一瞥【引用】：\(W_2\) 空间可视为无穷维黎曼流形（mfld 线预告），其上热方程 = 熵泛函的梯度流（JKO 格式）——"扩散 = 分布空间里的最速下降"：Fokker–Planck（sc-02）、Langevin 采样、扩散模型的又一层几何解读；分数阶推广与函数不等式（log-Sobolev）住在这条街【引用 Villani】。

3. 统计与计算的现实

经验分布的收敛速率（维数灾难，条件性结论）【引用 Dudley/Fournier–Guillin】：在指定的 \(W_2\) 风险口径、足够的矩/尾部控制与相应正则条件下，\(d>4\) 时常见的误差量级可写作 \(E\,W_2(\hat\mu_n, \mu)\lesssim n^{-1/d}\)；精确的上下界还依赖 \(p\)、维数、尾部、分布结构以及是否带对数因子，不能把这个幂率当成无条件的普遍等式。它说明高维下 OT 的样本复杂度会明显恶化（对比 KL 基于密度估计的困难：各有各的灾难）；工程对策：切片 OT（随机一维投影平均——一维可排序！ot-01 §3 的复用）、投影/低维结构假设、或熵正则化（下一页 Sinkhorn 的统计红利之一）。

4. 练习与要点

例 1（Brenier 显式解：高斯对高斯） \(\mu = N(m_1, \Sigma_1) \to \nu = N(m_2, \Sigma_2)\)；当协方差正定时，最优映射线性 \(T(x) = m_2 + A(x - m_1)\)，\(A = \Sigma_1^{-1/2}\big(\Sigma_1^{1/2}\Sigma_2\Sigma_1^{1/2}\big)^{1/2}\Sigma_1^{-1/2}\)（验证 \(A\) 对称正定 ⇒ 是凸函数 \(\frac12x^\top Ax + \cdots\) 的梯度 ✓），且

\[ W_2^2 = \|m_1 - m_2\|^2 + \mathrm{tr}\big(\Sigma_1 + \Sigma_2 - 2(\Sigma_1^{1/2}\Sigma_2\Sigma_1^{1/2})^{1/2}\big) \]

——这是高斯族上的 Bures/Wasserstein 闭式，并非一般高维分布唯一可闭式计算的情形；退化协方差需要用广义平方根或极限处理。FID 在指定的特征空间里，把样本均值与协方差代入这个 Gaussian Fréchet/Bures 公式，是对特征分布的二阶 Gaussian 近似；它忽略高阶结构，也有有限样本估计偏差，因此不能等同于原始特征分布的真实 \(W_2\)。

例 2（McCann vs 线性插值） \(\mu_0 = \delta_0, \mu_1 = \delta_1\)：McCann 给 \(\delta_t\)（点在走）；线性给 \((1-t)\delta_0 + t\delta_1\)（两点闪烁）——最小例子把"平移 vs 鬼影"看穿。

例 3（重心的体感） 两个相同形状、仅作平移的单峰直方图（峰在 0 与 10）：算术平均 = 双峰；\(W_2\) 重心 = 峰在 5 的单峰——"平均形状"与"形状的平均"之别。对任意单峰直方图不能无条件推出重心仍单峰；这里的结论依赖共同形状的平移结构。多受试者脑图谱、字体平均、气候情景合成选后者的理由。\(\blacksquare\)
