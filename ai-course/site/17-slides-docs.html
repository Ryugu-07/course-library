第 17 讲 · 实战：PPT 与文档

"帮我做个 PPT"大概是被辜负最多的期待——直接这么要，得到的多半是废话大纲配丑模板。原因很简单：一份好 PPT = 内容逻辑 + 视觉呈现两件事，LLM 精于前者、拙于后者。本讲的策略就一句话：让 AI 干透内容的活，用工具和模板锁死视觉的活，并给出四条从省事到精致的路径。

1. 先想清楚：PPT 的内容是"论证"，不是"文本"

无论走哪条路径，第一步都是让 AI 帮你把论证结构立起来，而不是直接产页面：

我要做一个 [15] 分钟的报告，听众是[非本方向的研究生]，
目标是让他们[理解 X 方法为什么优于传统做法]。
我的材料：[粘贴论文摘要/项目总结/要点清单]
请先给我：金字塔结构的大纲——一句话核心主张 → 3 个支撑论点 →
每个论点下 2-3 页的页标题（每页标题必须是一个完整的判断句，
如"检索质量决定生成上限"，而不是"背景介绍"这种空标签）。

"页标题 = 判断句"是麦肯锡式演示的核心纪律，AI 执行得极好——只要你要求了。大纲确认后，再让它逐页展开：每页 3–5 个要点短语（不是段落——满屏文字的 PPT 根源就是把讲稿贴上了页面）+ 一句"这页配什么图"的建议 + 讲者备注（你要说的话放备注，不放页面）。

2. 四条成稿路径

路径 工具 特点 适合
A. 大纲协作 + 手工排版 聊天框 + PowerPoint/Keynote 内容 AI、排版全手工，质量上限最高 重要报告、答辩
B. Markdown 转 slides Marp / reveal.js / Slidev 全程写文本，版式由主题包管，程序员友好 技术分享、课程
C. 智能体直产 pptx Claude 等（文档技能） 一句话到 .pptx 文件，可继续对话修改 快速初稿、内部汇报
D. 产品化工具 Gamma、AiPPT、Kimi PPT 等 网页端一条龙，模板漂亮，可控性一般 时间紧、要求不刁

路径 B 值得数理背景的你多看一眼——PPT 从此变成可版本管理的纯文本：

---
marp: true
theme: default
---
# 检索质量决定生成上限
- 三个证据：召回率 vs 最终准确率的相关性 …
- ![w:500](fig/recall_curve.png)

让 AI 直接生成整份 Marp markdown，一条命令渲染成 PDF/PPTX；改内容 = 改文本，AI 改起来也最顺手（它的母语就是 markdown）。

通用纪律（四条路径皆适用）：视觉一致性交给模板/主题（字体、配色、版式一次定死），别让 AI 逐页自由发挥；AI 生成的默认排版只当初稿，重要场合必须人工过一遍视觉。

3. 图的正确来源

页面上的图分三类，来源各不同（错配是学术翻车高发区，呼应第 16 讲）：

  • 数据图表：必须由代码从真实数据生成——让 AI 写 matplotlib/plotly 脚本（顺便要求"标注坐标轴、放大字号到演示可读"）；
  • 逻辑示意图（流程、架构、关系）：让 AI 写 Mermaid（文本描述的图表语言，graph LR; A-->B 这种），在线渲染后截图，改图 = 改文本；
  • 氛围插图：文生图（第 16 讲）。

4. 长文档：报告、申请书、手册

长文档的失败模式与 PPT 同源——一口气让 AI 写一万字，会得到结构涣散、前后重复的"注水文"。解法也是同一味药：编排（第 08 讲思想的文书版）：

  1. 骨架先行：先让它出"章节树 + 每节一句话主旨 + 各节之间的依赖关系"，你来批改这棵树——改结构比改文字便宜一百倍；
  2. 逐节生成：一次写一节，每次把"全文骨架 + 已写各节的摘要"喂回去（对抗上下文限制，保持全局一致）；
  3. 一致性收尾：全文完成后，专门跑一遍"审校 pass"——"检查术语是否全文统一、数据引用是否前后一致、各节是否有重复论述、语气是否一致"，这类全局巡检恰是 AI 的强项；
  4. 格式落地：交给智能体的文档技能直接产出 .docx（含目录、页眉、样式），或输出 markdown 后用 pandoc 转换。

模板化文书（会议纪要、周报、申请信）则更简单：给它一份你满意的旧例 + 本次的新信息，"照此风格与结构生成"——few-shot 的日常应用（第 08 讲）。

本讲小结

  • 分工铁律：AI 管内容逻辑，模板管视觉呈现；
  • 先立论证再产页面：金字塔大纲 + 判断句页标题 + 要点不成段；
  • 四条路径按场合选：重要的走 A/B，快糙的走 C/D；
  • 图有三个来源：数据图用代码、示意图用 Mermaid、插图用生图；
  • 长文档 = 骨架 → 逐节 → 一致性 pass → 格式落地。

动手：把你最近一次（或下一次）要做的报告，用第 1 节的提示词生成金字塔大纲，再选路径 B 或 C 产出初稿。对比你以往"直接开 PPT 软件从第一页做起"的流程，感受先后差异。

最后一讲：把全课程的方法收束到最重的写作场景——论文与长文。哪些环节 AI 能提速十倍，哪些环节一个字都不能让它替你写。
