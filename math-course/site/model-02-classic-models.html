建模 II · 经典模型谱（全站毕业典礼）

四个传世模型，每个都是"简单假设 → 深刻结论"的典范，也各自调用全站三四页的工具。读法建议：先自己按建模循环推一遍假设，再看模型——经典模型的价值不在结论而在示范"如何用最少的假设抓住机制"。

学习层：同一条曲线，先问它守住了什么

1. 具体实例：增长、传染、排队，哪个边界会先到？

把三个问题放到同一张预测桌上：一个产品的用户数会不会超过承载量，一个封闭人群的感染比例会不会先上升后回落，一个服务台的等待时间会不会在利用率接近 1 时失控。它们都能画出曲线，却不是同一种模型：一个有承载容量，一个有总人口守恒，一个只有在稳定条件下才有稳态队列。

2. 先预测：选模型，再押注边界

先选择增长、传染或排队模型，然后预测当前参数对应的行为：Logistic 会有界、SIR 会爆发还是消退、M/M/1 会稳定还是没有有限稳态。预测时同时写出你认为可观测的参数和不能由当前数据识别的参数；实验揭示后再对照守恒量、参数和适用域。

3. 最小模型：三种代表性骨架

增长用

\[ N'=rN\left(1-\frac{N}{K}\right), \]

传染用归一化的 SIR

\[ s'=-\beta si,\qquad i'=\beta si-\gamma i,\qquad r'=\gamma i, \]

排队用 M/M/1 的到达率 \(\lambda\)、服务率 \(\mu\)，利用率 \(\rho=\lambda/\mu\)。这三个骨架分别把容量、封闭人群和流量稳定性放在结论中心。

4. 正式桥：守恒、识别、适用域三栏同行

  • 守恒：Logistic 在 \(0\le N\le K\) 内保持区间，但没有“总量守恒”；SIR 满足 \(s+i+r=1\)；M/M/1 在稳态使用流量守恒 \(L=\lambda W\)，并要求 \(\rho<1\)。
  • 参数可识别性：增长早期的 \(r\) 容易被看到而 \(K\) 难以识别；SIR 的 \(\beta,\gamma\) 需要时间分辨率和干预信息才能分开；队列的 \(\lambda,\mu\) 通常要分别记录到达与服务时间。
  • 适用域：每个方程都依赖假设。模型输出是该假设下的条件预测，不是现实自动承诺的事实。

5. 误区与边界：toy 不是现实预测

  • SIR 的充分混合、固定参数和封闭人口会被网络结构、出生死亡和干预打破。
  • M/M/1 在 \(\rho\ge1\) 时不能套用有限的 \(W=1/(\mu-\lambda)\)；“满负荷更高效”在排队边界附近会反转。
  • Logistic 的 \(K\) 不是自然常数，早期数据可让多个 \(K\) 都拟合得不错；外推必须报告敏感性。
  • 课堂 toy 用来暴露机制与边界，不能冒充真实预测；真实项目要重新定义数据、校准、验证和干预域。

6. 迁移问题：增加一条机制，哪一栏必须重写？

给 SIR 加潜伏期、给队列加多服务台、给增长加季节 forcing，方程变长只是表面变化；守恒量、参数识别和适用域会一起变化。先重新做预测和边界检查，再决定是否值得引入更复杂模型。

无 JavaScript 时的静态 fallback：默认展示 Logistic 增长：\(N_0=80\)、\(K=600\)、\(r=0.35\) 时轨迹趋向 \(K\)，但这只说明该 toy 在固定容量假设下有界。脚本开启后可切换到 SIR 与 M/M/1，调整参数并在预测门后查看 SVG、守恒/稳定性账本、参数可识别性与适用域；这些输出不能代替真实数据验证。

1. 人口模型：从 Malthus 到 Logistic

Malthus（1798）：增长率正比于人口 \(N' = rN \Rightarrow N = N_0 e^{rt}\)——短期准、长期爆（资源无限的假设破产）。修假设（建模循环第 6 步的示范）：增长率随拥挤衰减 \(r(1 - N/K)\)：

\[ N' = rN\Big(1 - \frac{N}{K}\Big) \quad\Rightarrow\quad N(t) = \frac{K}{1 + Ce^{-rt}}\ \text{（S 形曲线）} \]

定性分析不解方程已知全局（ode-01 相线：\(N = K\) 稳定平衡）；无量纲化后无参数（model-01 例 3）。S 曲线的普适性：技术扩散、市场渗透、菌落生长——"先指数后饱和"是资源受限增长的通用形状（产品渗透率预测的第一模型）。

2. SIR 传染病模型（本页主菜）

假设：下面统一使用人口比例 \(s=S/N,i=I/N,r=R/N\)，所以 \(s+i+r=1\)；\(\beta\) 是每名感染者的有效接触率，充分混合使感染通量为 \(\beta si\)，康复通量为 \(\gamma i\)：

\[ s'=-\beta si,\qquad i'=\beta si-\gamma i,\qquad r'=\gamma i \]

不解方程读出全部大局（ODE 定性分析的展销会）：

  • 爆发判据：当 \(i>0\) 时，\(i'=i(\beta s-\gamma)>0\iff s>\gamma/\beta\)；若 \(i=0\)，则 \(i'=0\)，无感染是一个不变状态。全易感基准下的基本再生数与时变有效再生数分别为
\[ R_0=\frac{\beta}{\gamma},\qquad R_e(t)=R_0s(t). \]

一个感染者进入全易感人群时平均制造 \(R_0\) 个继发感染；实际初始增长条件是 \(R_e(0)=R_0s_0>1\)。因此即使 \(R_0>1\)，若初始易感比例已经足够低，感染仍会衰减。\(R_e(0)=1\) 是一阶阈值边界；口罩、隔离与免疫分别通过 \(\beta\) 或 \(s\) 改变它。这个数是模型内参数，不是脱离假设的命运开关；

  • 群体免疫阈值：在同质混合、疫苗完全阻断感染等理想条件下，使 \(R_e<1\) 需免疫比例 \(>1-1/R_0\)（\(R_0=3\Rightarrow67\%\)）；现实中的异质接触和效力衰减会改写这个阈值；
  • 感染人数何时转降？ 在 \(\beta,\gamma>0\)、\(s_0>0,i_0>0\) 的封闭 SIR 模型中，\(i\) 在 \(s<\gamma/\beta\) 时下降；若初始已低于阈值，就从一开始下降。用比例记号除去时间得 \(di/ds=-1+\gamma/(\beta s)\)，所以 \(i+s-(\gamma/\beta)\log s\) 守恒。令 \(i_\infty=0\)，得到 \(s_\infty-(\gamma/\beta)\log s_\infty=i_0+s_0-(\gamma/\beta)\log s_0\)；最终仍有 \(s_\infty>0\) 的易感者。这里的 \(s,i\) 都是比例，不能把人数 \(S,I\) 直接代入同一式。

模型的谱系繁殖：加仓室（SEIR 潜伏期）、加网络（放弃充分混合——图上的传染）、加随机（小人群用 Markov 链，随机过程 II）——"从骨架模型逐层加真"的教科书路径。信息传播/爆款扩散同构套用（"病毒式传播"是数学同构不是修辞）。

3. Lotka–Volterra 捕食者-猎物

\[ x' = x(a - by), \qquad y' = y(-c + dx) \qquad (x \text{ 兔}, y \text{ 狐}) \]

结论（ode-03 已证）：闭轨道永恒振荡，且轨道平均恰为平衡点 \((\bar x,\bar y)=(c/d,a/b)\)。若对猎物和捕食者施加同一按比例捕捞率 \(h\)，方程变为 \(x'=x[(a-h)-by],\ y'=y[-(c+h)+dx]\)，于是新平衡（也即闭轨道上的时间平均）为 \((\bar x_h,\bar y_h)=((c+h)/d,(a-h)/b)\)，其中 \(0<h<a\)。猎物平均数量增加、捕食者平均数量减少，这才是 Volterra 原理 的精确方向；并不是“捕食者占比上升”。模型解释了一战期间捕捞减弱后，捕食性鱼类比例为何可能上升，但真实生态还受年龄结构、季节和多物种网络影响。

4. 排队模型 M/M/1（随机过程的实战合成）

假设：顾客 Poisson 到达（率 \(\lambda\)，随机过程 I）、服务时间独立同分布为指数（率 \(\mu\)）、单服务台、先来先服务、无限等待空间且不拒绝到达——队长是生灭 Markov 链（随机过程 II/III）。在这些条件和稳态口径下，记 \(\rho = \lambda/\mu\)（利用率）；只有 \(\rho < 1\) 时才存在几何平稳分布 \(\pi_n = (1-\rho)\rho^n\)，并有：

\[ \text{平均队长 } L = \frac{\rho}{1 - \rho}, \qquad \text{平均逗留时间 } W = \frac{L}{\lambda} = \frac{1}{\mu - \lambda}\ \text{（Little 公式）} \]

读曲线（运营直觉的数学来源）：这个无限缓冲 M/M/1 的 \(L(\rho)\) 在 \(\rho \to 1\) 时发散——利用率 80% 时队长 4，95% 时 19，说明高利用率会急剧放大等待。有限缓冲、丢弃、优先级、批服务或非指数服务要换模型，不能直接套这条几何分布。Little 公式 \(L=\lambda W\) 的适用面更广，但也要求清楚定义稳态流量、在制数和逗留时间。

5. 收官：全站地图的用法

四个模型的工具账单：Logistic（ode + 相线）、SIR（ODE 定性 + 守恒量 + 一行代数改变政策）、L–V（ode-03 + 首次积分）、M/M/1（Poisson + Markov 平稳分布）——建模是全站知识的"组装车间"。此外的现代谱系各有出口：优化建模（生产/调度/组合——优化线四页）、统计与数据建模（回归/时序——统计线）、模拟建模（Monte Carlo——概率 V/数值 IV）、以及机理与机器学习的混血（灰箱——两门 AI 姊妹课程的世界）。

典型例题

例 1（SIR 政策算术） 某病 \(R_0 = 2.5\)，疫苗有效率 90%，需接种比例？\(p \cdot 0.9 \geq 1 - \frac{1}{2.5} = 0.6 \Rightarrow p \geq 67\%\)。（有效率折扣别忘——建模循环"解释"步的细节。）

例 2（M/M/1 容量决策） 客服 \(\lambda = 8\)/时，\(\mu = 10\)/时：\(\rho = 0.8,\ W = \frac{1}{10-8} = 0.5\) 时（30 分钟！）。若要 \(W \leq 10\) 分钟需 \(\mu \geq 14\)——服务能力要按等待目标反解，不按"够用"正推。

例 3（Logistic 拟合预警） 用前期数据拟合 S 曲线预测市场饱和量 \(K\)：拐点（\(N = K/2\)）之前的数据对 \(K\) 极不敏感（灵敏度分析！）——早期外推 \(K\) 的置信区间宽到没用（统计 III 的区间 + model-01 的验证步合演）。知道模型何时"还不能说话"，与会解模型同样重要。\(\blacksquare\)
