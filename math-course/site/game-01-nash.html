博弈论 I · 策略型博弈与 Nash 均衡

优化理论假设世界不还手；博弈论研究对手也在优化的世界——你的最优依赖他的选择，他的最优依赖你的。本页立好策略型博弈的语言，走到全学科的中心概念 Nash 均衡：它的定义只有一句话，存在性证明却要动用不动点定理——拓扑学在社会科学里最著名的一次出手。

学习层：均衡是存在、唯一，还是只是一个可怕的平衡？

1. 具体故事：两个应用要不要同时上线？

两家地图应用准备在同一座城市推出路线推荐。每家都可以选 早 或 晚 发布；收益同时记录市场份额和对方的损失。你不能只问“我的最佳动作是什么”，因为最佳动作取决于对方最后按下的按钮。

先不要看收益表的判定结果。对实验台的四个小博弈，逐个预测：

  1. 有多少个纯策略 Nash 均衡？
  2. 是否还存在双方都真正随机化的混合均衡？
  3. 在当前收益基数下的 payoff-sum maximizer（收益和最大格）是否一定是 Nash 均衡？

实验台在预测提交前隐藏最佳回应、均衡、payoff-sum maximizer 和 minimax 账本；先把“会发生什么”写下来，再让矩阵反驳你的直觉。

2. 正式桥：最佳回应是两条不等式，不是一个好结果

设行玩家的两个动作是 \(R_0,R_1\)，列玩家的两个动作是 \(C_0,C_1\)，收益格为

\[ G_{ij}=(u_{ij},v_{ij}),\qquad i,j\in\{0,1\}. \]

对固定的列 \(C_j\)，行玩家的最佳回应集合是

\[ BR_1(C_j)=\operatorname*{argmax}_{i\in\{0,1\}}u_{ij}; \]

对固定的行 \(R_i\)，列玩家的最佳回应集合是

\[ BR_2(R_i)=\operatorname*{argmax}_{j\in\{0,1\}}v_{ij}. \]

格 \((i,j)\) 是纯 Nash 均衡，当且仅当 \(i\in BR_1(C_j)\) 且 \(j\in BR_2(R_i)\)。这只说“没有单方面改按钮的收益动机”，没有说总收益最大。

若行玩家以 \(p\) 选 \(R_0\)，列玩家以 \(q\) 选 \(C_0\)，并写行收益矩阵为 \(\begin{pmatrix}a&b\\c&d\end{pmatrix}\)，列收益矩阵为 \(\begin{pmatrix}e&f\\g&h\end{pmatrix}\)，则真正的内点混合均衡必须满足对方无差异：

\[ q=\frac{d-b}{a-b-c+d},\qquad p=\frac{h-g}{e-f-g+h}. \]

只有 \(0<p,q<1\) 才是双方都使用两种动作的内点解；分母为零时不能做形式除法，必须回到最佳回应不等式检查边界或连续的一族均衡。有限博弈保证至少一个混合均衡，但不保证唯一。

3. 可操作实验：四种谱系放在同一台矩阵上

JavaScript 失效时的静态读法：收益对按“行玩家，列玩家”书写。最佳回应是逐列给行玩家找较大第一分量，再逐行给列玩家找较大第二分量。

预设 四个收益格（按 \(R_0C_0,R_0C_1,R_1C_0,R_1C_1\)） 纯 NE 混合/边界读法 当前 payoff-sum maximizer 与零和
优势策略 \((3,3),(0,5),(5,0),(1,1)\) \((R_1,C_1)\) 唯一 没有内点混合 \((R_0,C_0)\) 收益和 6，但不是 NE；非零和
协调 \((4,4),(0,0),(0,0),(2,2)\) \((R_0,C_0),(R_1,C_1)\) \(p=q=1/3\)；存在但不唯一 \((R_0,C_0)\) 收益和 8；非零和
Matching pennies \((1,-1),(-1,1),(-1,1),(1,-1)\) 没有 \(p=q=1/2\)；唯一 每格收益和 0；零和 minimax 值 0
退化边界 \((1,3),(1,0),(1,3),(1,0)\) \((R_0,C_0),(R_1,C_0)\) 行玩家完全无差异；\((p,C_0)\) 对所有 \(0\le p\le1\) 都是 NE payoff-sum maximizer 是 \(R_0C_0\) 与 \(R_1C_0\) 并列；非零和

这张表是静态后备，不替代实验中的逐格判定。尤其要把三句话分开：存在表示至少有一个均衡，唯一表示没有另一个均衡，payoff-sum maximizer 表示在当前收益基数下收益和最大；它们不是同义词。这里的收益和最大格不是独立仿射不变量：每位玩家各自平移只给每格加同一常数，但不同的正缩放会改变两位玩家收益在总和中的权重，因此可能改变最大格。

4. 误区与适用边界

容易说过头的句子 精确读法
“Nash 均衡就是最好的结果。” 它只排除单方面有利偏离；囚徒困境的均衡可以 Pareto 劣于另一个格。收益和最大格还只是在当前基数下的 payoff-sum maximizer。
“算出一组 \(p,q\) 就得到唯一均衡。” 内点公式只找内点候选；纯均衡、边界均衡和退化连续族仍要检查。
“存在性等于唯一性。” Nash 定理给有限博弈至少一个混合均衡，不给唯一性或选择机制。
“零和 minimax 可以用于任意收益矩阵。” minimax 等于均衡值是零和结构的结论；一般和博弈要分别保留两位玩家的收益与最佳回应。

实验求解的是精确的 \(2\times2\) 有限模型，不是学习动态、信念更新、重复博弈或真实市场预测。改变收益会改变均衡；“协调失败”还需要把沟通、制度和均衡选择机制放回模型。

1. 博弈三要素与囚徒困境

策略型（标准型）博弈：玩家集合、每人的策略集、每人的收益函数（依赖所有人的策略组合）。二人有限博弈写成收益矩阵。

囚徒困境（全学科的果蝇）：

对方沉默 对方招供
沉默 \((-1, -1)\) \((-10, 0)\)
招供 \((0, -10)\) \((-5, -5)\)

无论对方怎么选，"招供"都严格更优（优势策略）⇒ 双双招供 \((-5,-5)\)——尽管双双沉默 \((-1,-1)\) 对两人都更好。个体理性的合力可以是集体的灾难：军备竞赛、价格战、内卷、公地悲剧、刷分军备——全是这张 2×2 矩阵的换皮。它宣告了"看不见的手"的适用边界，也是后面一切"如何走出困境"讨论（重复博弈、机制设计）的靶子。

求解第一板斧：严格劣策略反复消去（IESDS）——理性的公共知识允许逐层删掉"任何情况下都不该用"的策略；能删到只剩一格最好，多数博弈删不动，于是需要——

2. Nash 均衡

定义 策略组合 \((s_1^*, \dots, s_n^*)\) 是 Nash 均衡：每个玩家的策略都是对其他人策略的最佳回应——单方面偏离不能获益：

\[ u_i(s_i^*, s_{-i}^*) \geq u_i(s_i, s_{-i}^*), \quad \forall s_i,\ \forall i \]

读法：不是"最优的结果"，是"自我强化的僵局"——一旦大家都这么玩，没人有动机先动（囚徒困境的双招供是 NE，尽管它糟糕：均衡 ≠ 效率，这是本页第二个重要教训）。纯策略 NE 的找法（划线法）：对每个对手策略列，给自己的最佳回应画线；双双画线的格子即 NE。

多重均衡与协调问题：猎鹿博弈（合作猎鹿 vs 各自抓兔）有两个纯 NE——(鹿,鹿) 高效但要互信，(兔,兔) 保守但稳。均衡选择靠博弈之外的东西：惯例、沟通、制度、焦点效应（Schelling point）——"为什么大家都靠右行驶"的数学位置。

3. 混合策略与存在性定理

猜硬币（我配你反）没有纯 NE——任何确定选择都会被对手利用。出路：随机化。混合策略 = 策略上的概率分布，收益取期望（概率 IV 上岗）。

无差异原则（手算引擎）：混合均衡中，你的混合概率必须让对手在其所用的纯策略间恰好无差异（否则他会全押更优的那个，你的混合就被利用）。例：猜硬币双方各 \(\frac12\)——让对手左右为难恰是自保（扑克的诈唬频率、点球的方向分布、猜拳的均匀随机都由此定量化）。

定理（Nash 1950） 任何有限博弈（有限玩家、有限策略）必存在至少一个（混合策略）Nash 均衡。

证明思路（一段话，值得记住轮廓）：先把每个纯策略嵌入其混合策略单纯形的顶点，也就是说纯策略是退化的混合策略。混合策略组合空间 \(X=\prod_i\Delta(S_i)\) 非空、紧且凸；期望收益连续，并且对每个玩家自己的混合策略是仿射的。于是最佳回应对应 \(BR_i(x_{-i})\) 非空、紧且凸值；有限策略下它具有闭图，因而上半连续。乘积对应 \(BR=\prod_iBR_i\) 把 \(X\) 映到非空紧凸子集，并满足 Kakutani 不动点定理（Brouwer 的集值推广）的全部条件：定义域非空紧凸、值非空紧凸、对应上半连续。不动点就是人人都在最佳回应的混合策略组合，纯策略均衡则是其中落在单纯形顶点的退化情形。\(\blacksquare\) ——与一般均衡存在性（Arrow–Debreu）同款武器；"均衡存在"这类经济学大定理的数学芯片都是不动点（泛函 I 压缩映像的非构造性亲戚：保证存在，不告诉你在哪——计算 NE 是 PPAD-难，另一个故事）。

4. 典型例题

例 1（划线法） 性别之战：\((2,1)\) 看球 / \((1,2)\) 看剧 / 错开各得 0。划线得两个纯 NE（一起看球、一起看剧）+ 一个混合 NE（各 \(\frac23\) 押自己偏好，期望收益 \(\frac23 < 1\)——混合均衡可以劣于任一纯均衡：协调失败有价）。

例 2（无差异原则手算） 上例的混合 NE：设男方以 \(p\) 看球，要让女方无差异：\(1\cdot p = 2(1-p) \Rightarrow p = \frac23\) ✓（注意：你的概率由对手的收益定——初学最反直觉的一步）。

例 3（公共品博弈） \(n\) 人各选贡献 0 或 1，总贡献翻倍均分：贡献 1 的私人回报 \(\frac{2}{n} < 1\)（\(n > 2\) 时）⇒ 全员搭便车是唯一 NE——囚徒困境的 \(n\) 人版；税收/强制缴纳社保的博弈论辩护词。\(\blacksquare\)
