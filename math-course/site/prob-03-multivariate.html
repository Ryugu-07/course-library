概率 III · 多维随机变量

现实问题几乎总是多变量的（身高与体重、收益与风险、图像的百万像素）。本页建立联合分布的语言，重点是三件事：边缘化（积掉不关心的）、条件化（固定已知的）、独立性判据——这三个动作正是概率图模型与贝叶斯推断的全部基本功。

学习层：看到一个点，先猜它属于哪一本概率账

1. 具体实例：两个传感器到底共享什么信息？

设 \(X\) 是温度偏差，\(Y\) 是湿度偏差。一次记录给出一个点 \((x,y)\)，但“这个点有多常见”至少有四种不同问法：联合概率描述 \((X,Y)\) 一起落在哪里，边缘概率只看一个传感器，条件分布描述知道 \(X=x\) 后 \(Y\) 如何改变，协方差只量线性联动。把它们都叫“分布”会让读数器悄悄串账。

下面的实验固定四个小世界：一个矩形上的独立模型、\(Y=X^2\) 的零协方差依赖、三角形支持上的密度 \(8xy\)，以及带可调 \(\rho\) 的二维正态。它们让“边缘一样”“支撑不同”“条件改变”和“线性相关”分别现形。

2. 先预测：打开联合图以前，先押四个判断

先不要提交实验。请写下你的预测：

  1. 若 \(X\)、\(Y\) 的联合密度能写成 \(g(x)h(y)\)，是否无条件就能断言独立？支撑集的形状会不会改变答案？
  2. \(X\sim U(-1,1)\)、\(Y=X^2\) 时，协方差为零是否意味着观察 \(X\) 后 \(Y\) 的分布不变？
  3. 对二维正态，调到 \(\rho=0\) 时，“不相关”和“独立”是否恰好重合？这个结论能否搬给任意分布？
  4. 只知道 \(X\)、\(Y\) 的两个边缘分布，能否唯一恢复联合分布？如果不能，缺的那一块结构通常由什么对象编码？

3. 正式桥：一张联合分布拆成三种读数

连续情形的三本基础账是

\[ f_X(x)=\int f(x,y)\,dy, \qquad f_{Y\mid X}(y\mid x)=\frac{f(x,y)}{f_X(x)}, \qquad f(x,y)=f_X(x)f_Y(y)\ \text{（独立时）}. \]

“可分离”还不够：独立要求等式在联合支持上成立，并且支持本身必须与两个边缘的允许取值相容。三角形 \(0<x<y<1\) 不是矩形，所以即使 \(8xy=(4x)(2y)\) 看起来可分，\(X\) 的取值仍会剪掉 \(Y\) 的可能范围，条件分布必然知道 \(x\)。

边缘相同也不代表联合相同。把两个边缘均匀分布粘成不同的联合结构，需要一个 copula；copula 记录依赖的排列方式，边缘分布负责各自的尺度。因而“边缘 + copula”才是联合结构的完整描述，而不是只看两个直方图。

协方差

\[ \operatorname{Cov}(X,Y)=E[XY]-E[X]E[Y] \]

只检查乘积的线性投影。独立一定推出零协方差（有二阶矩时），零协方差却可能与强烈的非线性关系共存；二维正态的 \(\rho=0\Longleftrightarrow X\perp Y\) 是特殊定理，不是通用定义。

4. 可操作实验：先过预测门，再揭示联合、边缘与条件

实验默认从“抛物线依赖”开始。提交四项预测后，才能看到支持/等密度 SVG、\(x\) 探针对应的条件读数和逐行表格；揭示后可切换模型、拖动 \(x\)，并在二维正态模型中调节 \(\rho\)。这些控件都会重新计算同一份解析账本。

JavaScript 失效时的静态 fallback： 默认模型为 \(X\sim U(-1,1),Y=X^2\)，探针取 \(x=0.5\)。其边缘为 \(X\sim U(-1,1)\) 与 \(f_Y(y)=1/(2\sqrt y)\)（\(0<y<1\)）；\(\operatorname{Cov}(X,Y)=E[X^3]=0\)，但 \(Y\) 是 \(X\) 的确定函数，所以不独立，且 \(Y\mid X=0.5\) 集中在 \(0.25\)。对照模型读法如下：

模型 联合 / 支持 边缘与条件 独立性与失败边界
矩形独立 \(f=1/4\) 于 \(-1<x<1,-1<y<1\) 两个边缘均匀；条件不随探针改变 独立；矩形支持是关键
抛物线依赖 质量在 \(y=x^2\) 上 \(X\) 均匀；\(Y\) 的密度为 \(1/(2\sqrt y)\)；条件为点质量 协方差为零但不独立；支持是奇异曲线
三角支持 \(f(x,y)=8xy\) 于 \(0<x<y<1\) \(f_X(x)=4x(1-x^2)\)，\(f_Y(y)=4y^3\)；\(Y\mid X=x\) 的密度为 \(2y/(1-x^2)\) 不独立；可分形式不能越过非矩形支持
二维正态 \(N(0,0,1,1,\rho)\) 的椭圆等密度线 条件均值为 \(\rho x\)，条件方差为 \(1-\rho^2\) 仅在二维正态中 \(\rho=0\) 等价于独立

这里的表格是解析 fallback，不是随机样本的 Monte Carlo 估计；图形只显示固定网格或等密度轮廓，不能把一张散点图当成独立性的证明。

5. 定理与失败边界：每次边缘化都要带条件

  • 联合、边缘、条件不是同义词。 \(f_X\) 是对 \(y\) 的积分，\(f_{Y\mid X}\) 还要除以 \(f_X(x)\)；分母为零或不在边缘支持上时，条件密度不能这样直接写。
  • 独立性看整个联合结构。 需要联合分布因子化并且支持相容；非矩形支持、隐藏约束和 copula 依赖都可能让两个边缘看起来“无关”而联合并不独立。
  • 零协方差只是一张线性筛子。 \(Y=X^2\) 是最短反例；高阶依赖、尾部联动和条件均值的变化都可能被协方差漏掉。
  • 二维正态的特权要标注适用域。 对一般分布，不相关不能推出独立；对高维正态，协方差矩阵对角才给出联合独立。
  • 条件分布是预测器。 知道 \(X\) 后应读取 \(Y\mid X=x\)，不能拿边缘 \(f_Y\) 代替；在三角支持中，\(x\) 甚至会改变 \(Y\) 的可行区间。

回到正文公式时，先问“我手里的是联合、边缘还是条件”，再问“支持和矩条件是否允许这一步”。这两个问题比背下一个可分离公式更可靠。

1. 联合分布、边缘与条件

联合分布函数 \(F(x, y) = P(X \leq x, Y \leq y)\)。连续型有联合密度：\(F(x,y) = \int_{-\infty}^x\int_{-\infty}^y f(u,v)\,du\,dv\)，\(P((X,Y) \in D) = \iint_D f\)（二重积分上岗，数分 VI）。

边缘分布（"积掉不关心的变量"）：

\[ f_X(x) = \int_{-\infty}^{+\infty} f(x, y)\,dy \]

⚠️ 联合定边缘，边缘定不了联合（不同的联合可以有相同的边缘——相关结构丢了）。

条件密度（"固定已知的变量再归一化"）：

\[ f_{Y\mid X}(y \mid x) = \frac{f(x, y)}{f_X(x)} \qquad \Longleftrightarrow \qquad f(x,y) = f_X(x)\,f_{Y\mid X}(y\mid x) \]

后一形式是联合分布的链式分解——先采样 \(X\) 再按条件采样 \(Y\)。🔗 一切生成式建模的形式骨架（ai 课 03/07 讲；扩散模型的 \(q(x_{1:T}\mid x_0) = \prod q(x_t \mid x_{t-1})\) 也是它）。

2. 独立性

\(X, Y\) 独立 \(\iff F(x,y) = F_X(x)F_Y(y) \iff f(x,y) = f_X(x)f_Y(y)\)（几乎处处）。

实用判据：密度可分离变量 \(f(x,y) = g(x)h(y)\) 且支撑集是矩形（长方形区域）⇒ 独立。⚠️ 支撑集不是矩形（如单位圆盘上的均匀分布）时哪怕形式可分也不独立——\(X\) 的取值限制了 \(Y\) 的范围。

独立的继承性：\(X \perp Y \Rightarrow g(X) \perp h(Y)\)。

3. 多维随机变量的函数

和的分布（卷积公式） \(Z = X + Y\)，\(X \perp Y\)：

\[ f_Z(z) = \int_{-\infty}^{+\infty} f_X(x)\, f_Y(z - x)\,dx \]

（不独立时把被积函数换成联合密度 \(f(x, z-x)\)。）三大可加族（独立同族相加不出族，参数相加——考试与建模都高频）：

族 结论
正态 \(N(\mu_1, \sigma_1^2) + N(\mu_2, \sigma_2^2) = N(\mu_1{+}\mu_2,\ \sigma_1^2{+}\sigma_2^2)\)
泊松 \(P(\lambda_1) + P(\lambda_2) = P(\lambda_1 + \lambda_2)\)
二项 相同成功概率 \(p\) 的独立二项变量相加，试验次数相加
Gamma 相同 rate（或相同 scale 约定）的独立 Gamma 变量相加，形状参数相加
\(\chi^2\) 独立 \(\chi^2\) 变量相加，自由度相加；这是统计页抽样定理的引擎

最值分布（独立时）：

\[ F_{\max}(z) = \prod_i F_i(z), \qquad F_{\min}(z) = 1 - \prod_i \big(1 - F_i(z)\big) \]

（记忆：最大值小于 z = 全都小于 z；最小值的对偶。名例：独立指数的 min 仍是指数，参数相加——"串联系统寿命"。）

商与积：分布函数法通吃；或二维变量替换公式（Jacobi 行列式版，数分 VI 换元的概率应用）。

4. 二维正态（多维正态的门面）

密度由五参数 \((\mu_1, \mu_2, \sigma_1^2, \sigma_2^2, \rho)\) 决定（指数上是二次型——高代 VI 正定矩阵在此现身：一般 \(n\) 维正态 \(N(\boldsymbol\mu, \Sigma)\) 的密度 \(\propto \exp\big({-\frac12}(x-\boldsymbol\mu)^\top\Sigma^{-1}(x-\boldsymbol\mu)\big)\)，\(\Sigma\) 为协方差矩阵）。

四条性质（重要级别拉满）：

  1. 边缘仍正态：\(X \sim N(\mu_1, \sigma_1^2)\)；
  2. 条件仍正态，且条件期望是线性的：\(E[Y \mid X = x] = \mu_2 + \rho\frac{\sigma_2}{\sigma_1}(x - \mu_1)\)（线性回归在正态世界是精确解而非近似——统计页回归的源头；条件方差 \(\sigma_2^2(1-\rho^2)\) 与 \(x\) 无关）；
  3. 对二维正态：不相关 \(\iff\) 独立（一般分布只有 ⇐！这是正态的特权，考试第一陷阱）；
  4. 线性组合仍正态（正态族对线性运算封闭——这是它成为"计算最友好分布"的原因，🔗 Kalman 滤波、高斯过程、扩散模型全靠这条性质做闭式推导，comfy 课 02 讲的闭式跳跃公式即"性质 4 + 可加性"）。

5. 典型例题

例 1（边缘与条件全流程） \(f(x,y) = 8xy,\ 0 < x < y < 1\)（注意三角形支撑集）。 解：\(f_X(x) = \int_x^1 8xy\,dy = 4x(1 - x^2)\)；\(f_{Y\mid X}(y\mid x) = \frac{8xy}{4x(1-x^2)} = \frac{2y}{1-x^2}\ (x < y < 1)\)。独立吗？形式 \(8xy\) 可分离，但支撑集非矩形——不独立（也可验证 \(f \neq f_X f_Y\)）。

例 2（卷积） \(X, Y \overset{iid}{\sim} U(0,1)\)，求 \(Z = X + Y\) 的密度。 解：\(f_Z(z) = \int f_X(x)f_Y(z - x)dx\)，被积为 1 的区域是 \(0<x<1\) 且 \(0<z-x<1\)：\(z \in (0,1]\) 时长度 \(z\)；\(z \in (1,2)\) 时长度 \(2 - z\)。得三角分布 \(f_Z(z) = z \wedge (2-z)\)。（两个均匀相加就开始"中间高两头低"——CLT 的最小演示，概率 V 呼应。）

例 3（min 指数） 两元件寿命独立 \(\mathrm{Exp}(\lambda_1), \mathrm{Exp}(\lambda_2)\)，串联系统寿命 \(T = \min\)：\(P(T > t) = e^{-\lambda_1 t}e^{-\lambda_2 t}\) ⇒ \(T \sim \mathrm{Exp}(\lambda_1 + \lambda_2)\)。\(\blacksquare\)
