读完一条研究方法路线，最后应能交出什么？不必立刻完成一项庞大调查，但应能把一个问题、取得的材料、分析决定和结论连接起来，让别人顺着这条路检查，也能指出哪里需要重做。

本讲提供一个可以从头复算的微型研究。两家媒体、六个事件和十二条标题全部为本课虚构。 它们是练习材料，不代表真实媒体差异。你可以先遮住参考编码，自己做一次，再与解析比较；不需要联系真实受访者或收集个人资料。

第一步：让问题小到能够回答

最初的问题是“哪家媒体更关心普通人”。这个问题包含动机、资源投入、采访深度与报道效果，十二条标题无法回答。把它缩小为：“在这六个相同公交事件上，两家媒体的标题呈现普通乘客声音的比例是否不同？”

这里研究的是标题中的可见性。标题没有呈现乘客，不等于正文没有采访乘客；标题出现乘客声音，也不证明记者采纳了乘客立场或解决了他们的问题。缩小问题不是放弃重要性，而是先回答材料能够支撑的一步。

在看分类结果前，写下分析计划：比较每家六条标题中的声音比例，保留事件配对，并检查争议编码是否改变结论。现实研究还要提前确定媒体、时间窗口和事件进入样本的条件。不能先寻找差异最大的标题，再把这批标题称为两家媒体的日常表现。

第二步：建立材料表和编码规则

本练习的规则是：标题明确把陈述、评价或愿望归给普通乘客、居民、学生等使用者，记为 1；没有明确归属，或只出现运营方、施工方的声音，记为 0。直接引语和明确归属的间接表述都可以计入，不根据立场赞成或反对决定编码。

“乘客盼增加班次”明确归属愿望，按本规则计 1；“增开班次惠及乘客”只说受益者，计 0。把两句都算作乘客声音，会把被报道者与获得表达位置的人混在一起。规则是否足够细，可以通过编码分歧来检查。

你可以下载这份练习材料 CSV。其中保留两名虚构编码者的原始判断、参考裁决和争议说明，以演示复核过程；这些列是教学设计，并非真实完成过双人标注的研究记录。

真实材料表还应保存标题访问日期、来源、网页版本、事件配对理由及缺失情况。标题被编辑过时，不能把今天的标题与另一天保存的正文混成同一版本。对转载、重复页和同一标题的多次更新，也需要事先规定如何处理。

第三步：先独立判断，再讨论分歧

设虚构编码者一按照表中规则编码；编码者二只在 A05 记成 0，因为他把“乘客盼”误当成记者自己的概括，没有识别出愿望已明确归属于乘客。十二条中十一条一致，一致率是 11 ÷ 12 ≈ 91.7%。查到原因后，二人依据“明确归属的间接表述也算”裁决为 1。

这个过程表明分歧在哪里，不表明 91.7% 是所有研究都足够好的标准。类别极不平衡时，一致率可能很高；更大研究可使用适当的一致性指标并检查类别分布。裁决后当然可以达到一致，但不能把裁决后的 100% 当成两名编码者原本独立判断的表现。

如果这次讨论暴露了规则缺陷，研究者应记录修改，并重新检查所有可能受影响的标题。不能只把唯一争议行改掉，留下其他按旧规则完成的行。独立编码、协商裁决和最终分析是不同阶段，表格最好分别保存。

第四步：计算比例，再回到每个事件

参考编码中，甲有 5 条呈现乘客声音，乙有 2 条。两家各六条，因此甲是 5/6 ≈ 83.3%，乙是 2/6 ≈ 33.3%，差为 50 个百分点。这不是“高 50%”；若报告相对于乙的比例增长，则是 150%，但在这么小的样本中，这种表达容易放大气势而遮住五条与两条的事实。

还可以按事件配对看：三个事件是甲有、乙无；两个事件两家都有；一个事件两家都没有；没有事件出现甲无、乙有。这样可以确认差异并非来自两家选择了完全不同的六个事件。配对减少一种混淆，却没有控制报道时点、标题长度、文体及编辑策略。

不用代码也能复算。在表格软件中按媒体筛选，计数并对参考编码求和即可。愿意使用 Python 的读者，可以在下载文件所在目录运行：

import csv

with open("research-project.csv", encoding="utf-8-sig", newline="") as f:
    rows = list(csv.DictReader(f))
rates = {}
for outlet in ("甲", "乙"):
    group = [r for r in rows if r["outlet"] == outlet]
    yes = sum(int(r["reference_voice"]) for r in group)
    rates[outlet] = yes / len(group)
    print(outlet, yes, len(group), round(100 * rates[outlet], 1))
print("差异（百分点）", round(100 * (rates["甲"] - rates["乙"]), 1))

代码只汇总指定列，不检查标题理解是否正确。运行成功与测量有效是两种验收。小项目保留原表的好处，是别人无需相信这几行代码，就能检查每一步。

第五步：主动寻找让结论变弱的条件

暂把唯一争议行 A05 编为 0，其余仍按原规则判断，甲变成 4/6，乙仍为 2/6，差为 33.3 个百分点。这是一个明确的单行敏感性检查：争议行改变差异大小，但在这份材料里不改变方向。它不是对所有可能编码偏差的穷尽，也不是置信区间；若正式改为更窄的定义，则需重新编码全部材料。

如果另一位研究者提出“正文才是普通人是否被认真听见的关键”，现有分析无法驳倒这个意见。可以增加正文中的声音归属、段落位置、是否提供回应和解释等变量，重新提出问题。不能拿标题结果去填补没有分析的正文。

如果质疑是“这十二条本来就是你挑出来展示差异的”，对于本练习，回答是对的：它们确实是为教学编制的。正因为如此，这里不计算一个显著性数字来宣称发现了真实媒体规律。未来真实项目若只取得便利样本，也不能仅凭软件输出的区间消除选择偏差。

第六步：写出别人能够反驳的结论

一段合格的练习结论可以这样写：“在本课编制的六组同事件标题中，按明确归属普通使用者陈述或愿望的规则，甲有五条、乙有两条呈现乘客声音，比例相差五十个百分点。改变一条争议编码后差异缩小，方向保持。本结果描述这份教学材料，不推断真实媒体、记者动机或受众效果。”

这段话看似收敛，实际给出了可核查的主张、规则、数量和改变条件。下一步最值得做的，是确定一个真实且可合法使用的小型材料范围，预先记录入样与编码规则，试编后修订，再在尚未用于修订的材料上检查规则。

若你的问题关于受众理解，需要另行设计受众研究；若关于新闻生产，需要采访或观察相关流程；若关于接触报道造成什么变化，则需要合适的因果设计。方法不是课程末尾随便挑一个工具，而是从问题开始就受到约束的证据路径。

第七步：整理一份轻量而完整的交付

最终材料可以只有研究说明、材料目录、编码手册、分析表和修订记录五部分。写清哪些分析提前计划、哪些是看到结果后提出；探索性分析可以有价值，但不应伪装成原本预测。预注册可帮助留下时间记录，也不保证假设好、执行正确或结论必真。

能够公开的材料应足够让别人重算主要结果；有版权、参与者约定或再识别风险的材料则说明访问限制，并提供允许共享的摘要、汇总或合成示例。保留必要版本即可，不需要为每次复核复制整个项目。

作为本课程的结业练习，你可以交付这份微型研究的重新编码版，或者提出一个新项目。评价重点是问题是否与材料匹配、规则能否执行、反例是否得到处理、结论是否有边界。样本更大、图更复杂或模型更新，都不能替代这四件事。

练习：现在由你来验收这份研究

1. 请不看代码，写出甲乙的比例、差异和配对结果。

甲 5/6，约 83.3%；乙 2/6，约 33.3%；差为 50 个百分点。三对仅甲有声音，两对两家都有，一对两家都没有。这个配对描述控制了所选事件不同的问题，未控制报道阶段与其他编辑条件，也不构成媒体类型的因果效果。

2. 把所有没有引号的标题都记为 0，为什么不能只修改 A05？

新规则会影响 A01、A02、A03、A04 与 B03 等原本以冒号或间接方式明确归属声音的标题。必须重新检查全部材料，并承认现在测量的是更窄的“出现引号的直接引语”，已改变原问题。本课只改单行的敏感性检查，是专门检验 A05 争议，不是全面实施新定义。

3. 如果你想声称甲更能增进公众理解，下一步缺什么？

首先需要明确“理解”是哪种能力，例如能否说明调整原因和受影响群体，再取得受众层面的证据。标题内容只提供可能机制，不能代替理解测量。观察受众成绩还会遇到自选阅读等混淆；若要判断报道引起的变化，需建立适当比较与因果假设。
