宇宙学 II · 热历史与 CMB

对标：Ryden §8–11 ｜ 前置：cosmo-01、sm-03（Planck 谱/统计）、atom-01（核） 早期宇宙 = 一锅按 \(T \propto a^{-1}\) 降温的热汤——统计物理 + 粒子物理在膨胀背景上的应用题。本页沿温度轴走三站：原初核合成（前三分钟的元素工厂）、复合与 CMB（宇宙的婴儿照）、以及 CMB 声学峰如何变成精密宇宙学的标尺。暴胀作为开篇问题的答案一瞥收尾。

学习层：冻结不是温度刻度，而是一场 rate race

1. 先过预测门：降温时谁跑得更快？

本页实验故意只保留一个无量纲的 rate-race toy。令

\[ x\equiv \frac{T}{T_f},\qquad \frac{\Gamma}{H}=x^{m-n},\qquad \left.\frac{\Gamma}{H}\right|_{x=1}=1. \]

冷却意味着 \(x\) 从 \(x>1\) 经过 \(1\) 走向 \(x<1\)。在打开账本前，先回答：

  1. 当 \(m>n\) 时，降温后 \(\Gamma/H\) 下降、保持不变，还是上升？
  2. 归一化后 \(x=1\) 的 \(\Gamma/H\) 是多少？
  3. \(m=n\) 时 \(\Gamma/H\) 全程相同；这是否足以定义一个孤立的冻结时刻？
  4. \(m<n\) 时，冷却对应 freeze-out，还是 recoupling？

预测门会先隐藏曲线、当前点和数值账本；答完后再切换预设与 \(x\)，检查自己的量词和方向判断。

2. 静态 fallback：同一个 crossing，不同的方向

无 JavaScript 时仍可读：比例常数已经被归一化到 \(x=1\)，所以所有预设在 \(x=1\) 都有 \(\Gamma/H=1\)。诊断约定为：\(\Gamma/H>1\) 表示反应快、仍有维持平衡的能力；\(\Gamma/H<1\) 表示反应慢、进入脱耦候选区；\(\Gamma/H\approx1\) 只是量级边界，不是瞬时开关。

预设 \((m,n)\) \(\Gamma/H\) \(x=2\) \(x=1\) \(x=0.5\) 冷却方向 / crossing 读法
弱作用 × 辐射期 \((5,2)\) \(x^3\) \(8\) \(1\) \(0.125\) 下降；\(x=1\) 是 freeze-out 方向的量级 crossing
温和 freeze-out toy \((3,2)\) \(x\) \(2\) \(1\) \(0.5\) 下降；同样在 \(x=1\) crossing
equal-exponent \((2,2)\) \(1\) \(1\) \(1\) \(1\) 全程相等；没有孤立 crossing，也没有由此定义的冻结时刻
recoupling toy \((1,3)\) \(x^{-2}\) \(0.25\) \(1\) \(4\) 上升；冷却后靠近平衡，是 recoupling 方向

透明账本逐行记录 \(x\)、\(\Gamma/H\)、平衡/脱耦诊断和量词（\(x>1\)、\(x=1\) 或 \(x<1\)）。双对数图的斜率就是 \(m-n\)，所以 equal-exponent 的水平线与 recoupling 的反向斜率不会被“看到 \(x=1\)”这一件事混为一谈。

无 JavaScript 时的静态 fallback：

模型只回答 rate race，不直接给出丰度。默认弱作用 × 辐射期为 \(m=5,n=2\)，故 \(\Gamma/H=x^3\)；冷却到 \(x=0.5\) 时比值为 \(1/8\)，从平衡侧走向脱耦候选侧。改变预设后，必须重新读斜率和诊断，不能把所有 \(x=1\) crossing 都叫 freeze-out。

反例与迁移：\(m=n\) 给出整条 \(\Gamma/H=1\) 水平线，不能凭一个等号制造冻结时刻；\(m<n\) 则冷却使比值上升，说明 recoupling 方向。若恢复未归一化的比例常数 \(C\)，模型会变成 \(\Gamma/H=Cx^{m-n}\)，并且 \(m\ne n\) 时 crossing 移到 \(x=C^{-1/(m-n)}\)；这正是为什么本实验不能把 \(T_f\) 当成无条件的实测温度。

3. 边界：rate race 不是丰度计算器

  • 比例常数被归一化掉了；真实 \(\Gamma\) 和 \(H\) 还会随 \(g_*\)、质量阈值、反应道、化学势和非热分布改变，单一幂律指数只是一段局部 toy。
  • \(\Gamma/H\approx1\) 是量级判据，不是反应在某个瞬间被关掉的开关；真实 Boltzmann 方程需要连续演化和初始条件。
  • 不从这个 toy 直接计算 BBN 丰度、WIMP relic abundance 或 CMB 参数。迁移时应把真实反应网络、膨胀史和碰撞项逐项补回。

1. 热历史的通用法则

降温律：辐射主导时 \(T \propto a^{-1}\)（sm-03 光子气 + \(a^{-4}\) 稀释——热汤按膨胀冷却）。冻结（freeze-out）法则：反应维持平衡的条件是反应率 > 膨胀率 \(\Gamma \gtrsim H\)——降温使 \(\Gamma\) 骤降、某刻反应"来不及" ⇒ 丰度冻结：宇宙学的核心机制（下面每一站都是它的实例；"非平衡遗迹 = 今日可观测物"——宇宙是台天然的非平衡实验装置）。

2. 原初核合成（BBN，\(t \sim\) 3 分钟）

剧本【机理链】：\(T \gtrsim 1\) MeV：中子质子经弱作用互变平衡，\(\frac{n}{p} = e^{-\Delta mc^2/k_BT}\)（Boltzmann 因子——sm-02 的日常汇率）；弱作用冻结（\(T \approx 0.8\) MeV）时 \(\frac np \approx \frac16\)，再经中子衰变到 \(\approx\frac17\)；\(T \approx 0.07\) MeV 时氘瓶颈打开、几乎全部中子被焊进 \(^4\)He：

\[ Y_{He} = \frac{2(n/p)}{1 + n/p} \approx 25\% \]

【推导一行 + 意义】 质量占比约 25% 的氦——在给定核反应率、重子密度、有效中微子种类和热历史近似后的可检验参数化预测，不是“无参数预言”；痕量氘/锂的丰度对重子密度和核反应网络敏感。与 CMB 的比较可以形成交叉检验，但必须把这些输入和误差模型一起写明。

3. 复合与 CMB（\(t \approx 38\) 万年）

复合：\(T \sim 0.3\) eV 时电子被质子俘获成中性氢（滞后于 13.6 eV 一大截——光子数超重子约 \(10^9\) 倍，高能尾巴持续电离：Saha 方程的账【引用】）；光子失去散射对象（Thomson 截面的电子没了——ced-02 例 2 退场）——宇宙变透明，末次散射面的光自由飞行至今。标准热历史常把最后散射的红移记作 \(z\sim1100\)，这是模型与重组计算下的近似标尺，不是单独一条无条件常数。

CMB 单极与涨落：在指定的黑体拟合和温标约定下，单极温度常写作约 \(2.725\) K；FIRAS 的结果支持极高精度的黑体形状。各向异性通常是 \(10^{-5}\) 量级，但具体数值依赖地图、去除单极/偶极和所选多极范围；它们是结构初始条件的证据，不是“当代最完美纪录”的口号。

声学峰（婴儿照的指纹）【机理级】：复合前光子-重子流体在暗物质引力井中振荡（压强 vs 引力——弹簧；mech-04 的振动在宇宙尺度返场）；复合瞬间"快门按下"，不同波长的模式冻结在不同相位——功率谱（球谐分解 \(C_\ell\)——mp-01 球谐的宇宙级岗位）出现峰列。读数规则：第一峰位置主要约束声学尺度 \(\theta_* = r_s/D_A\)；曲率推断还需要整套峰列、声学视界、距离模型、重子/暗物质成分和参数化，第一峰不能单独直接等于曲率。峰高比提供组分信息，但“锁定六参数”也只是在指定 ΛCDM 模型与数据集下的拟合陈述。

4. 暴胀一瞥（开篇问题的答案候选）

三大疑难：视界问题（天各一方的 CMB 为何同温——从未有过因果接触）、平坦问题（\(\Omega_k \approx 0\) 需要初值精调）、遗迹问题。暴胀方案：极早期常用 \(\sim e^{60}\) 量级作为典型 benchmark，而不是直接观测到的膨胀倍数（de Sitter 相，cosmo-01 例 2 的机制放在开头）——小因果区被吹成整个可观测宇宙（同温解释 ✓）、曲率被拉平 ✓；红利：量子涨落被拉出视界冻结成经典密度涨落——结构的种子是量子涨落（qm 线与宇宙学的惊人接线），预言近标度不变谱；谱指数的具体拟合值依赖数据集、参数化和扰动模型，本页不把某个当期数字写成定理。诚实标注：暴胀是"标准候选"而非定论（具体模型未锁定、原初引力波 B 模尚未探得——第三档了望塔边界）。

5. 练习与要点

例 1（冻结判据练手） 在给定反应率归一化、热分布和辐射期近似下，弱作用常写成 \(\Gamma \propto T^5\)、\(H \propto T^2\)：\(\Gamma = H\) 给出一个 MeV 量级的 \(T_f\) 估计——这只是 rate-race 的量纲练习，系数与 Boltzmann 演化仍需另算；同一机理可迁移到暗物质 relic 题，但不能从这里直接读出丰度。

例 2（CMB 光子今何在） 若把单极近似为 \(T=2.725\) K 的黑体，Planck 分布积分给出约 \(411/\mathrm{cm}^3\) 的光子数密度；这个数依赖温标和黑体假设，是条件化的参考计算，不是动态纪录口号。它说明“宇宙背景”是一个可计算的热场，而不是老电视雪花的百分比类比。

例 3（声学标尺算术） 在一组参考 ΛCDM 参数下，声学视界可取约 \(150\) Mpc（共动）、末次散射面距离约 \(14\) Gpc，于是 \(\theta \sim 0.6^\circ\)、\(\ell_1 \approx \frac{\pi}{\theta} \approx 220\)。这是声学尺度的量级推算，不是第一峰单独直接测出曲率；完整曲率结论要回到整套 \(C_\ell\) 和参数拟合。\(\blacksquare\)
