计算物理 III · 偏微分方程与有限元

对标：Strang & Fix An Analysis of the Finite Element Method / Brenner–Scott The Mathematical Theory of Finite Element Methods ｜ 前置：fl-01（连续介质与守恒律）、数学站 Sobolev/弱导数线 本页问题：一根有热源的细杆，为什么把微分方程“在每一点强行满足”改成积分形式，反而更容易得到稳定、可收敛、能核对能量的数值解？有限元的关键不是画出一条平滑曲线，而是把物理边界、弱形式和离散功率账放进同一个线性系统。

学习层：先看能量账，再看温度曲线

1. 具体谜题：网格变密时，解为什么应该变好？

取长度为 \(1\) 的稳态细杆，温度为 \(u(x)\)，导热系数为 \(\kappa>0\)，两端固定为零温度，并在杆内加入源项：

\[ -(\kappa u')'=A\pi^2\sin(\pi x),\qquad u(0)=u(1)=0. \]

当 \(\kappa=A=1\) 时，精确解是 \(u(x)=\sin(\pi x)\)，所以 \(u(1/2)=1\)。计算机不直接表示连续函数，而是选择网格节点和一组局部线性基函数。问题变成：这些有限个系数能否同时满足边界、源项做功和导热耗散的关系？

2. 先预测，再揭示

打开实验台以前，先回答四个问题：

  1. 有限元的核心方程是逐点强形式、测试函数下的弱形式，还是随机游走？
  2. 对光滑解、正的 \(\kappa\) 和正确装配，加密网格后最大节点误差通常上升、下降，还是完全不变？
  3. 什么条件使热传导刚度矩阵具有正定性：\(\kappa>0\)、\(\kappa=0\)，还是 \(\kappa<0\)？
  4. 离散解满足线性方程时，离散能量 \(u_h^TKu_h\) 与载荷功 \(f^Tu_h\) 应该相等，还是互为相反数？

3. 静态后备：一个可手算的有限元账本

无 JavaScript 时的静态读法。默认实验取 \(A=1\)、\(\kappa=1\)、\(N=16\) 个等长单元，使用 \(P1\) 线性单元，并对每个单元的载荷积分使用中点规则。精确解仍是 \(u=\sin(\pi x)\)。在最粗的 \(N=4\) 网格上，节点 \(x=1/2\) 的解析值是 \(1\)，有限元值约为 \(0.972872\)；更细网格时这个差异继续下降。

局部刚度矩阵是

\[ K^{(e)}=\frac{\kappa}{h}\begin{pmatrix}1&-1\\-1&1\end{pmatrix}, \]

中点载荷向量为 \(f^{(e)}\approx h\,s(x_e)(1/2,1/2)^T\)，其中 \(s(x)=A\pi^2\sin(\pi x)\)。\(N=4\)、\(h=1/4\) 时，内部三行组成一个对称正定三对角系统；解出后中心节点接近 \(1\)。对于默认 \(N=16\)，实验表格还会显示最大误差约 \(1.61\times10^{-3}\)、离散 \(L^2\) 误差约 \(1.14\times10^{-3}\)，误差随 \(N\) 以接近二阶的速率下降。具体末位会随浏览器浮点舍入改变，但能量账应满足

\[ u_h^TKu_h=f^Tu_h \]

到机器精度；这条等式比一张“看起来像正弦”的曲线更有诊断力。

检查 默认模型的预期读数 它证明不了什么
解析中心温度 \(u(0.5)=1\) 只属于这个源项与边界
\(\kappa\) 的符号 \(\kappa=1>0\)，刚度正定 负导热系数不是普通热方程
离散能量账 \(u_h^TKu_h-f^Tu_h\approx0\) 不能代替连续模型推导
\(N=4\to8\to16\) 最大误差按约 \(1/4\) 下降 只在光滑、渐近、同一模型下
线性单元形状 单元内是折线，节点处贴近 exact 不能把 \(P1\) 折线称为处处精确

实验把温度曲线、双对数收敛图、残差和能量平衡一起显示。若只看当前网格的拟合，可能漏掉积分规则、边界处理或矩阵装配的错误；若只看误差，也可能漏掉一个稳定地解错了物理方程的程序。

4. 证据等级

  • 线性系统残差接近零，说明“代码解出了它装配的离散系统”。
  • 网格收敛说明离散系统在当前正则性和积分精度下逼近连续问题。
  • 能量恒等式说明离散解尊重弱形式的功率结构。
  • 这些都是有限数值证据；要把它外推到尖角、激波、材料界面或三维复杂网格，必须重新检查正则性、稳定性和误差估计。

1. 从稳态传热到弱形式

先把物理写成守恒律。Fourier 定律给热流 \(q=-\kappa u'\)；稳态时“流入的热量 + 内部发热 = 流出的热量”，于是

\[ -(\kappa u')'=s(x). \]

假定 \(u\) 足够光滑，把方程乘以在边界为零的测试函数 \(v\)，在 \([0,1]\) 上积分：

\[ \int_0^1 -(\kappa u')'v\,dx=\int_0^1s v\,dx. \]

分部积分得到

\[ \underbrace{\int_0^1\kappa u'v'\,dx}_{a(u,v)} =\underbrace{\int_0^1s v\,dx}_{\ell(v)} +\underbrace{[\kappa u'v]_0^1}_{0}. \]

边界上 \(v=0\)，所以 Dirichlet 边界项消失。若边界给的是热流而不是温度，边界项不会消失，它就会成为自然边界载荷；这正是弱形式把边界物理放进方程的地方。

连续问题的能量泛函是

\[ \mathcal E(u)=\frac12\int_0^1\kappa(u')^2dx-\int_0^1s u\,dx. \]

对允许的扰动 \(v\) 求一阶变分，正好得到 \(a(u,v)=\ell(v)\)。因此稳态温度是“导热耗散和源项做功之间的平衡”，不是一条由绘图软件猜出来的曲线。

2. 有限元空间与刚度矩阵

把区间切成 \(N\) 个单元，节点为 \(x_i=ih\)、\(h=1/N\)。\(P1\) 有限元空间由连续的分段线性函数组成，标准帽函数 \(\phi_i\) 满足 \(\phi_i(x_j)=\delta_{ij}\)。近似解写成

\[ u_h(x)=\sum_{j=1}^{N-1}U_j\phi_j(x), \]

两端的系数因 Dirichlet 条件固定为零。令测试函数依次取 \(\phi_i\)，得到矩阵方程

\[ KU=f,\qquad K_{ij}=a(\phi_j,\phi_i),\qquad f_i=\ell(\phi_i). \]

在一个长度为 \(h\)、常导热系数为 \(\kappa\) 的单元上，局部矩阵为

\[ K^{(e)}_{\mathrm{local}}=\frac{\kappa}{h}\begin{pmatrix}1&-1\\-1&1\end{pmatrix}. \]

它的两个行和为零，反映“只整体平移温度，不产生梯度耗散”的事实。把相邻单元按共享节点装配后，内部矩阵是稀疏三对角：对角项来自两侧单元，邻对角项来自共享边。局部到全局的索引映射是程序最容易写错的地方，因此一个好的验证先检查对称性、正定性和已知边界解，而不是先增加网格数量。

对源项 \(s=A\pi^2\sin(\pi x)\)，精确积分可以通过高阶求积完成；本页实验选用中点规则，令

\[ f_i\approx\sum_e h\,s(x_e)\phi_i(x_e). \]

中点规则很透明：它明确展示了“积分误差也是离散误差的一部分”。如果把精确解换成尖峰源、把 \(\kappa\) 换成单元间跳变或把网格改成不均匀，就需要重新评估求积阶数，不能把这一张表的二阶数字当成普遍承诺。

3. 稳定性来自强制性，而不只是矩阵可逆

对任意非零的离散函数 \(v_h\)，

\[ a(v_h,v_h)=\int_0^1\kappa(v_h')^2dx. \]

当 \(\kappa(x)\ge\kappa_0>0\) 时，除零边界函数外，\(v_h'\) 不可能处处为零，于是 \(a(v_h,v_h)>0\)。这就是 coercivity（强制性）在本例中的物理含义：任何非平凡温度梯度都消耗正的导热能量。有限维里它对应刚度矩阵对称正定，保证解唯一，并让共轭梯度等方法有良好的基础。

若 \(\kappa=0\)，方程不再是传热扩散问题；若 \(\kappa<0\)，矩阵可能失去正定性，得到的“温度”不再代表普通材料的稳定导热。若常系数只被整体缩放为 \(\varepsilon\kappa\)，则 \(K=\varepsilon K_0\)，相对条件数并不会因此改变，虽然解的量级与绝对敏感度会按 \(1/\varepsilon\) 放大。真正恶化相对条件数的典型来源是网格加密、\(\kappa(x)\) 的大空间反差或系数逼近退化；这不是通过把残差打印得更小就能消除的。

离散能量账来自矩阵方程本身：左乘 \(U^T\) 得

\[ U^TKU=U^Tf. \]

左边是每个单元 \(\kappa(U_{i+1}-U_i)^2/h\) 的和，右边是源项对离散温度做的功。实验把两者的差作为独立证据；若曲线看似合理但这个差很大，通常意味着边界载荷、局部矩阵符号、右端装配或求积实现有问题。

4. 收敛：误差究竟在什么意义下变小

设连续解足够光滑。对 \(P1\) 元，典型有限元估计在一维写成

\[ \|u-u_h\|_{H^1}\le C h\,\|u\|_{H^2}, \qquad \|u-u_h\|_{L^2}\le C h^2\,\|u\|_{H^2}. \]

节点最大误差在本页的规则网格与光滑正弦例子上也呈现接近二阶的趋势，但“最大节点误差二阶”不是所有网格和所有解的自动定理。若解只有 \(H^{1+s}\) 正则性，阶数会下降；若源项是 delta 分布、几何有尖角，或者系数发生不受处理的跳变，经典估计需要局部网格加密和更精细的界面条件。

做收敛实验时必须固定物理问题，只改变 \(h\)。记录

\[ e_N=\max_i|U_i-u(x_i)|, \qquad \|e_N\|_{L^2,h}=\left(h\sum_i|U_i-u(x_i)|^2\right)^{1/2}, \]

并用相邻网格估计阶数

\[ p_N=\log_2\frac{e_N}{e_{2N}}. \]

如果 \(p_N\) 只有在最粗网格很大、细网格突然降到零，优先怀疑精确解评估、边界节点或浮点抵消；如果残差很小而误差不随网格下降，说明“解离散问题”与“离散问题逼近目标问题”被混淆了。

5. 稳定性、条件数与边界条件

本页是椭圆问题，没有像显式热方程那样的时间步长 CFL 条件；但仍有三类稳定性要核对。

第一是物理强制性：\(\kappa\) 必须保持正，边界条件要排除常数零模。若两端都改成纯 Neumann，刚度矩阵会有常数零空间，解只在总热流兼容且加一个平均温度规范后唯一。

第二是离散稳定性：网格不能有退化单元，映射后的 Jacobian 不能变号；二维三角形的极小角会恶化条件数，即便矩阵仍然正定。

第三是线性代数稳定性：直接消元要有主元策略，共轭梯度要配合预条件；“残差 \(10^{-14}\)”只是在当前浮点系统中满足方程，不是误差一定同样小。实验输出 Thomas 消元的最小正主元，作为一维正定性的数值哨兵。

Dirichlet 边界不能简单把边界行删掉就忘记右端修正。一般的分块系统是

\[ \begin{pmatrix}K_{II}&K_{IB}\\K_{BI}&K_{BB}\end{pmatrix} \begin{pmatrix}U_I\\U_B\end{pmatrix} =\begin{pmatrix}f_I\\f_B\end{pmatrix}, \]

给定 \(U_B\) 后内部右端应使用 \(f_I-K_{IB}U_B\)。本页 \(U_B=0\)，这笔修正恰好消失；换成非零端温度时不能照抄零边界代码。

6. 可复现验证清单与失败边界

一个可审计的有限元算例至少留下以下记录：方程和单位、材料系数、源项、网格节点、单元类型、求积规则、边界处理、线性求解器容差、残差、物理能量账和网格收敛表。固定这些信息以后，另一个实现才有机会区分“浮点末位不同”和“装配逻辑不同”。

常见误区：

  • “网格越细越准确。”只有在网格质量、求积、边界和线性求解误差没有成为新瓶颈时才成立；过细网格也会放大条件数和舍入影响。
  • “残差为零就是误差为零。”残差衡量当前离散方程，误差还包含离散、求积、模型和边界误差。
  • “有限元就是把曲线连起来。”曲线只是结果的可视化，真正决定它的是弱形式和刚度/载荷矩阵。
  • “稳定正定意味着材料模型正确。”正定只说明当前数学问题有好的能量结构；各向异性、温度依赖、辐射边界和相变源项仍需物理建模。

迁移任务：把本页的一维杆换成二维薄板，在左边施加热源、上下边界绝热、右边固定温度。先预测自然边界项如何进入弱形式，再设计三组网格：均匀、靠近热源加密、故意有瘦长单元。比较温度峰值、能量平衡和收敛阶，解释为什么“局部加密”可能比把所有单元一律加倍更节省，同时指出薄板出现材料界面时要怎样改写通量连续条件。
