# NGC3198 课程数据包

数据由 Federico Lelli、Stacy McGaugh、James Schombert 的 SPARC 项目发布。请引用 Lelli, McGaugh & Schombert (2016), AJ 152, 157，并在需要时引用样本表所列的原始旋转曲线文献：Daigle et al. (2006)、Begeman et al. (1991)、Begeman (1987)。[原作者数据入口](https://astroweb.case.edu/SPARC/)。

- MassModels_Lelli2016c.mrt、SPARC_Lelli2016c.mrt 是 2026-09-10 下载的完整上游字节快照，保留原始表头、单位和文献说明。
- NGC3198-extract.txt 逐字保留质量模型表中该星系的全部 43 行，未删除负气体项或大误差点。
- NGC3198.json 是课程生成的结构化提取；不是 SPARC 另发的数据产品。实验 JS 嵌入相同的数值以便离线阅读，不在加载时联网更新。
- 上游完整文件的 SHA-256 与提取规则记录在 manifest.json。上游可后续修订；本课程的版本固定。

“原始文件”只表示本课程没有改动上游字节。这些是已校准并做过动力学/几何处理的发布旋转曲线与质量模型，不是仪器原始信号。NGC3198 的采用距离为 13.8±1.4 Mpc、平均倾角为 73±3°、质量标志为 Q=1；表列速度误差不含完整倾角系统误差。

Vgas 已包含 1.33 的氦修正，Vdisk/Vbul 对应 3.6 μm 波段质量光度比 1。平方贡献使用 V|V|；负 Vgas 表示外侧环带产生向外的径向力贡献，不表示负质量。该星系的核球贡献列全零。本课参数化暗晕、有限扫描、残差和 Jeans 模型为课程派生计算，不能标为 SPARC 官方拟合或作者背书。

公开科学数值保留作者归属和引用，不将其声称为课程原创，也不以仓库代码许可证改变上游资料的归属。数据入口与说明以作者站和原论文为准。
