高量 I · 对称性与角动量理论

对标：Sakurai Modern QM §3–4 ｜ 前置：qm-03、mech-02（Noether）、抽代 I（群） 研究生量子力学的第一主题：对称性从“解题技巧”升格为“理论的组织原理”。本页三件事：对称性算符的一般理论（Wigner 定理）、角动量的合成（CG 系数）、以及对称性如何锁死矩阵元（Wigner–Eckart 定理——选择定则的总后台）。

学习层：矩阵的对易、能级简并和禁戒跃迁如何互相照应？

1. 具体情境：一组有限自旋矩阵能看出什么

先把 \(\hbar=1\)，在自旋 \(j=1/2\) 的二维空间中写出 \(J_x,J_y,J_z\)。如果它们真的构成角动量表示，那么交换子应回到另一个生成元；如果一个有限维哈密顿量与 \(J_z\) 对易，能级是否必然成二重简并？最后，用一个矢量算符的三个球分量检查：从 \(m=+1/2\) 出发，哪些 \(m'\) 可能留下非零矩阵元？

实验台先隐藏矩阵诊断与选择定则账本，请先预测：

  1. \([J_x,J_y]\) 应该等于 \(iJ_z\)、\(J_z\)，还是零？自旋 \(1/2\) 与自旋 1 会不会遵守同一关系？
  2. “\([H,J_z]=0\)”是否单独保证简并？在等距的 \(H_0=E I\)、轴向 Zeeman 模型和倾斜微扰模型中，哪一个命题可以从对易性推出，哪一个只是数值结果？
  3. 对矢量算符分量 \(T_q\)，从 \(m=+1/2\) 出发时，\(q=0,+1,-1\) 分别允许哪些 \(m'=m+q\)？不满足磁量子数守恒的格子应当是严格零还是“很小”？

2. 正式桥：表示恒等式、动力学模型与选择定则

角动量表示满足

\[ [J_i,J_j]=i\,\varepsilon_{ijk}J_k, \qquad J^2=J_x^2+J_y^2+J_z^2=j(j+1)I. \]

这些是表示级恒等式；只要使用标准有限维 \(su(2)\) 表示，矩阵计算应在舍入容差内返回零。升降算符系数

\[ J_\pm|jm\rangle=\sqrt{j(j+1)-m(m\pm1)}\,|j,m\pm1\rangle \]

同时给出有限矩阵的带状结构和维数 \(2j+1\)。实验台会分别显示 \(j=1/2\) 与 \(j=1\) 的维数、交换子残差和 Casimir 残差。

动力学还要另说。若 \([H,U(g)]=0\)，对称性把能量本征空间映到自身；若一个不可约表示完整地落在同一能级，才得到由表示维数控制的简并。只与某个生成元 \(J_z\) 对易，并不自动制造多重简并：\(H=E I\) 是二重简并，\(H=E I+\omega J_z\) 却把两个 \(m\) 分开。加入倾斜项 \(\epsilon J_x\) 后，\([H,J_z]\neq0\) 的数值证书说明轴向对称性被破坏，但不等于所有物理对称性都消失。

Wigner–Eckart 的几何部分在有限账本里表现为

\[ m'=m+q,\qquad |j-j'|\le k\le j+j'. \]

对固定的不可约张量变换律，违反这些条件的 CG 系数严格为零；允许的格子仍需约化矩阵元决定是否真的非零。于是“选择定则”是表示论证书，“某个实验跃迁很弱”还要加入动力学、近似和实验分辨率。

3. 动手核对：把精确表示与近似 Hamiltonian 分账

实验台先要求预测，再显示矩阵的 SVG 热图、对易性/简并性表格和 \(q=-1,0,+1\) 的选择定则账本。矩阵元素用固定的有限精度计算，不抽样；重置会恢复 \(j=1/2\)、轴向模型和空的预测状态。

JavaScript 失效时的静态读法：\(\hbar=1\)，矩阵基底按 \(m=j,j-1,\ldots,-j\) 排列。

账本层 精确或有限模型 应读出的结论
表示恒等式 \(j=1/2\) 与 \(j=1\) 的 \(J_i\) \([J_x,J_y]-iJ_z=0\)，\(J^2-j(j+1)I=0\)；这是表示定义的精确身份
对称与能级 \(H_0=2I\)；\(H_z=2I+0.6J_z\)；\(H_{tilt}=2I+0.6J_z+0.08J_x\) \(H_0\) 二重简并；\(H_z\) 与 \(J_z\) 对易但分裂；\(H_{tilt}\) 的 \([H,J_z]\) 残差非零
选择定则 \(j=j'=1/2,k=1\)，比较 \(q=-1,0,+1\) \(m'=m+q\) 是几何允许条件；超出有限基底的格子严格为零，允许格子仍由约化矩阵元决定

前两行的“零”是有限矩阵对恒等式的精确检验（浮点显示会有舍入残差）；第二行的能级与对易范数是给定 toy Hamiltonian 的数值证据，不是对真实原子谱的普遍定理。

4. 假设、失败边界与物理解释

  • 表示假设：使用有限维、Hermitian 的标准 \(su(2)\) 表示并取 \(\hbar=1\)；无穷维轨道表示、域问题和反酉时间反演不由本实验覆盖。
  • 简并边界：对易性给出不变子空间，不单凭一个对易算子保证简并；简并还可能被边界、外场、微扰或不同不可约表示的能量重合改变。
  • Kramers 边界：时间反演对称只有在反酉算子满足 \(T^2=-1\) 的半整数自旋情形才给出 Kramers 成对简并；“有时间反演对称”本身不足以推出该结论。
  • 选择定则边界：Wigner–Eckart 需要旋转对称性与不可约张量变换律；CG 为零是严格禁戒，CG 非零不保证跃迁强度非零，也不替代径向积分和宇称条件。
  • 数值边界：SVG 中的“残差小”是机器精度下的有限证据；它不能证明一般矩阵族的对易性，更不能把一个近似 Hamiltonian 的参数结果冒充真实系统定律。

1. 量子对称性的一般理论

Wigner 定理【引用】：保持一切跃迁概率 \(|\langle\phi|\psi\rangle|^2\) 的变换必为酉或反酉算符——对称性在量子力学里的合法形态只有这两种（反酉的唯一常客：时间反演）。

连续对称性 = 酉群 = 生成元：\(\hat U(\theta) = e^{-i\theta\hat G/\hbar}\)——平移由动量生成、转动由角动量生成、时间平移由哈密顿量生成（Schrödinger 方程本身）。对整个一参数群都有 \([\hat U(\theta),\hat H]=0\) 时，微分得到 \([\hat G,\hat H]=0\)；若 \(G\) 无显含时间且域条件合适，Ehrenfest 方程再给 \(\frac{d\langle G\rangle}{dt}=0\)。这是 Noether 思想的量子版本，但单个离散角度的 \(U\) 对易不能一般反推出生成元对易。

简并的对称性起源：\([\hat G, \hat H] = 0\) 且 \(|\psi\rangle\) 为本征态 ⇒ \(\hat G|\psi\rangle\) 同能量；只有当群作用确实把态送到线性无关的同能态时，这一步才产生简并——简并子空间 = 对称群的表示空间（抽代 I 群论在物理的正式岗位：氢原子 \(2\ell + 1\) 重简并 = \(SO(3)\) 的表示维数；"意外简并" = 更大的隐藏群——Runge–Lenz 的 \(SO(4)\)【引用】）。离散对称性同框：宇称 \(\hat P\)（本征值 \(\pm1\)——选择定则的另一位签发人）、时间反演（反酉；只有 \(T^2=-1\) 时才有 Kramers 成对简并【引用】）。

2. 角动量合成与 CG 系数

两个角动量 \(j_1 \otimes j_2\) 的合成（自旋+轨道、双电子……）：积空间按总角动量分解——

\[ j_1 \otimes j_2 = |j_1 - j_2| \oplus \cdots \oplus (j_1 + j_2) \]

（维数对账 \(\sum(2j+1) = (2j_1+1)(2j_2+1)\) ✓。）换基系数即 Clebsch–Gordan 系数 \(\langle j_1m_1j_2m_2|JM\rangle\)。

构造算法【推导流程】：最高态 \(|J{=}j_1{+}j_2, M{=}J\rangle = |j_1j_1\rangle|j_2j_2\rangle\) 唯一 → 降算符 \(\hat J_- = \hat J_{1-} + \hat J_{2-}\) 逐级往下 → 正交性补出下一多重态的顶——机械可执行（例 1 演示最小案例）。选择规则 \(M = m_1 + m_2\)、三角不等式——不满足者系数恒零。

样板（两个自旋 ½）：\(\frac12\otimes\frac12 = 1 \oplus 0\)——三重态（对称）+ 单态（反对称）\(\frac{1}{\sqrt2}(|\!\uparrow\downarrow\rangle - |\!\downarrow\uparrow\rangle)\)：单态就是最大纠缠态（qi-01 的 Bell 态提前出生）、氦原子的正/仲态、核磁的单三态——一次合成吃遍三个领域。

3. Wigner–Eckart 定理（选择定则的总后台）

张量算符：在转动下按角动量 \(k\) 的表示变换的算符族 \(\hat T^k_q\)（标量 \(k=0\)、矢量 \(k=1\)——偶极算符 \(\hat{\mathbf r}\) 是 \(k=1\) 的三分量）。

定理（Wigner–Eckart）

\[ \langle \alpha' j'm'|\hat T^k_q|\alpha jm\rangle = \langle jm; kq|j'm'\rangle\,\langle\alpha'j'\|\hat T^k\|\alpha j\rangle \]

——矩阵元 = CG 系数（纯几何，查表）× 约化矩阵元（纯动力学，一个数）。 【骨架】 对易关系 \([\hat J_\pm, \hat T^k_q]\) 与 CG 的递推完全同构 ⇒ \(m\)-依赖被对称性完全锁死。\(\blacksquare\)

读法（分工宣言）：对称性管"形状"、动力学只出"一个整体系数"——固定 \(\alpha,\alpha',j,j',k\) 后，整组磁量子数矩阵元由一个约化矩阵元控制。直接红利：选择定则。对电偶极算符，\(k=1\) 的三角规则先允许 \(\Delta\ell=0,\pm1\)（并排除 \(0\leftrightarrow0\)），而位置算符的奇宇称再排除 \(\Delta\ell=0\)，合起来才得 \(\Delta\ell=\pm1\)；同时 \(\Delta m=0,\pm1\)。同一多重态内的分支比可由 CG 平方比给出，但径向约化矩阵元仍由动力学决定。

4. 练习与要点

例 1（CG 亲手构造） \(\frac12\otimes\frac12\)：从 \(|11\rangle = |\!\uparrow\uparrow\rangle\) 起降一级得 \(|10\rangle = \frac{1}{\sqrt2}(|\!\uparrow\downarrow\rangle + |\!\downarrow\uparrow\rangle)\)，正交补出 \(|00\rangle\)——五分钟把算法走通（§2 样板的全部系数到手）。

例 2（选择定则速判） 氢 \(3d \to 1s\) 偶极跃迁？\(\Delta\ell = 2\)——CG 三角规则 \((2, 1, 0)\) 不成立 ⇒ 禁戒（只能双光子或级联）——亚稳态与激光介质选材的判据。

例 3（投影定理应用） 在一个无额外重数的固定不可约 \(j\) 子空间内，矢量算符投影到该子空间后与 \(\hat{\mathbf J}\) 成比例（W–E 的 \(k=1\) 特例）：Landé g 因子 \(g_J = 1 + \frac{j(j+1)+s(s+1)-\ell(\ell+1)}{2j(j+1)}\) 由 \(\hat{\boldsymbol\mu}\cdot\hat{\mathbf J}\) 投影一行导出。若同一 \(j\) 出现多份不可约表示，还需保留重数空间上的矩阵结构。
