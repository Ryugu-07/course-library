课程地图

沿着完整路线阅读

28讲完整路线，适合无社会学基础、愿意细读与计算的读者。理论入口指向具体问题中的分析单元；不同作者的概念会在后续案例中继续比较。虚构案例与教学数据均明确标注，真实研究注明研究对象、来源和证据限制。

01教育、阶层与流动用一个完整问题单元练习：区分现象、重建理论、比较证据，判断教育怎样改变人生机会。＋
  1. 扩招之后，机会更平等了吗？

    从两张明确虚构的教学表出发，分清入学率、机会差距、绝对流动与相对流动。

    正文可读
  2. 学校怎样评价能力？

    细读布迪厄的文化资本、惯习与场域，重建家庭资源如何经由教育评价转化为优势。

    正文可读
  3. 同一现象，可以有怎样不同的解释？

    比较表现、选择与学历门槛，学会说明一项研究支持到哪里、仍有哪些解释未被排除。

    正文可读
  4. 做一次教育机会研究

    从问题到样本、测量与比较，练习设计可被证据纠正的研究。

    正文可读
02劳动、市场与阶级从工作的一天进入所有权、劳动过程、市场嵌入与阶级关系。＋
  1. 谁决定工作怎样完成？

    从劳动过程进入马克思的分析，区分劳动能力、控制和产品的归属。

    正文可读
  2. 阶级是收入排行榜吗？

    比较马克思与韦伯的问题意识，讨论所有权、市场处境、地位与人生机会。

    正文可读
  3. 市场依赖哪些社会条件？

    阅读波兰尼，追问劳动力、土地与货币如何被纳入市场，区分历史论证和规范主张。

    正文可读
  4. 灵活工作，谁承担风险？

    用平台劳动材料分析管理、议价、合同和社会保障，检验经典概念的边界。

    正文可读
03规则、权威与组织理解社会秩序的来源，也观察规则在实际组织中如何变化。＋
  1. 陌生人为什么能够合作？

    阅读涂尔干关于分工和团结的论证，辨认规范与相互依赖的作用。

    正文可读
  2. 命令为什么被服从？

    区分权力、权威与正当性，重建韦伯的分析工具及其理想类型方法。

    正文可读
  3. 规则越多，组织越有效吗？

    从办事流程追踪专业分工、形式规则、非正式关系与目标替代。

    正文可读
  4. 共同利益为什么不自动带来合作？

    比较行动成本、信任、制度和资源动员，用具体案例判断各解释适用条件。

    正文可读
04互动、身份与文化把微观观察变成分析，理解角色、标签和情境怎样组织日常生活。＋
  1. 我们怎样向别人呈现自己？

    细读戈夫曼的互动分析，观察情境与观众如何影响行动。

    正文可读
  2. 一个标签怎样改变人生轨迹？

    区分行为、分类与制度回应，讨论偏差研究及其证据。

    正文可读
  3. 认识谁，会改变得到什么吗？

    学习关系强弱、网络位置与资源，避免把一切关系都叫作社会资本。

    正文可读
  4. 媒体怎样改变我们对社会的认识？

    区分信息选择、议程、传播网络与受众解释，设计能区分机制的比较。

    正文可读
05乡土、城乡与迁移从费孝通的问题意识进入关系结构、城乡制度与迁移经验。＋
  1. 怎样读懂“差序格局”？

    把《乡土中国》放回其分析对象，解释关系秩序及概念的适用边界。

    正文可读
  2. 来到城市，就进入同一种生活了吗？

    结合住房、公共服务、劳动与家庭材料，分析城市内部差异。

    正文可读
  3. 迁移为什么经常沿着已有关系发生？

    比较机会、家庭策略、网络与制度，阅读迁移研究的不同证据。

    正文可读
  4. 一个地区的解释能搬到另一个地区吗？

    练习历史比较和案例选择，辨别表面相似与机制相同。

    正文可读
06家庭、照护与性别把有酬与无酬劳动放进同一张图，理解家庭和制度之间的关系。＋
  1. 家庭内部怎样分配时间和资源？

    从家庭整体转向成员之间的劳动、议价与责任。

    正文可读
  2. 社会运行依赖谁的照护？

    进入女性主义社会理论与照护研究，追踪家庭、市场和公共服务之间的分工。

    正文可读
  3. 相同制度为什么产生不同处境？

    分析劳动分工、组织规则和性别规范的共同作用，避免单一原因解释。

    正文可读
  4. 一项政策的效果应该怎样判断？

    比较时间、收入、服务可及性与群体差异，区分目标、实施和实际结果。

    正文可读
07把判断变成可检验的研究集中整理贯穿全课的方法，完成一份有证据、有反驳、有边界的社会分析。＋
  1. 访谈和田野怎样产生知识？

    练习提问、观察、记录与解释，讨论研究者位置及匿名保护。

    正文可读
  2. 社会统计中的分母、比较与因果

    学习抽样、测量、选择偏差和不确定性，理解回归能回答什么。

    正文可读
  3. 理论分歧究竟发生在哪一步？

    重建概念、机制和可观察结果，识别竞争解释、互补解释与价值判断。

    正文可读
  4. 完成你自己的社会问题分析

    用一个明确问题贯穿材料选择、理论比较、反驳与修订，给出可检查的研究边界。

    正文可读

另一条阅读路径

沿着一位作者的论证深入

从问题进入，也可以带着问题回到原典。以下入口对应具体课程单元；完整的思想家原典课程仍需逐步建设。

  • 本单元可读

    布迪厄：文化资本与教育评价 ↗

    从第2讲的校园评价案例进入资本、惯习与场域的关系，并依阅读指向回到原典。当前开放的是教育问题中的理论单元。

  • 本单元可读

    布东：表现与教育选择 ↗

    从第3讲区分初级与次级效应，比较同一转衔中的表现、成本、信息和选择机制，连读后续实证研究。

  • 本单元可读

    马克思：劳动过程与阶级 ↗

    从第5讲的劳动控制与产品归属进入马克思的劳动过程分析，接第6讲比较阶级和人生机会。

  • 本单元可读

    波兰尼：市场与社会条件 ↗

    从第7讲的用工、土地与货币安排进入波兰尼的论证，区分市场组织的社会条件与规范主张。

  • 本单元可读

    涂尔干：分工与社会团结 ↗

    从第9讲的维修合作重建分工、规范与社会团结的关系，接组织和集体行动案例。

  • 本单元可读

    韦伯：权威、组织与人生机会 ↗

    从第10讲区分权力、正当性和理想类型，连读第6讲市场处境与第11讲组织规则。

  • 本单元可读

    戈夫曼：互动与自我呈现 ↗

    从第13讲的咖啡店观察情境、观众与角色，理解戈夫曼如何分析共同维持的互动秩序。

  • 本单元可读

    费孝通：乡土关系与社会变迁 ↗

    从第17讲把差序格局放回《乡土中国》的分析对象，再讨论关系秩序与概念跨情境使用的边界。

  • 本单元可读

    女性主义社会理论：劳动、照护与制度 ↗

    从第22讲追踪照护如何在家庭、市场与公共服务之间分配，连读家庭议价和组织规则；比较多种女性主义研究。
