# 第 14 讲 · 放大与精修流水线

> 直出分辨率被训练桶锁死在 1024 左右（第 08 讲），潜空间还吞掉了小脸和细纹理（第 04 讲）。把"能看"变"能用"（壁纸、印刷、头像特写）靠的是后处理流水线：**放大** + **补细节** + **修脸手**。原理都在第 05 讲第 4 节，本讲拼装成三条实用管线。

## 1. 三条放大管线（按质量与成本递增）

### 管线 A · 纯前馈超分（秒级，零显存压力）

```text
成图 ─▶ Load Upscale Model(4x-UltraSharp / RealESRGAN_anime) ─▶ Upscale Image (using Model) ─▶ Save
```

一个专训的小卷积网络直接 4×（第 05 讲：前馈路线）。快、绝对忠实原图、不会画错任何东西——但也**不添任何新细节**，放大到 4K 后细看是"干净的糊"。用途：批量出货、社交媒体尺寸、给管线 B 打底。动漫图记得用 anime 专版（`RealESRGAN_x4plus_anime_6B`），通用版会把线条磨肉。

### 管线 B · 两段式 hires（质量主力，标准答案）

原理：**先放大再用低 denoise 图生图"把细节画出来"**——放大后的每个区域重新过一遍扩散，模型在更大画布上真正生成新细节（第 09 讲 denoise 机制的直接应用）：

```text
KSampler(1024 直出) ─▶ VAE Decode ─▶ 管线A 放大 2× ─▶ VAE Encode
   ─▶ KSampler #2 (denoise 0.3-0.45, 同提示词同底模) ─▶ VAE Decode ─▶ Save
```

关键参数就一个：**第二段的 denoise**。0.3 = 忠实补细节；0.45 = 细节更丰富但开始有自由发挥；0.55+ = 大图上按第 08 讲的"复影"规律开始长出多余结构。第二段 steps 给 15–20 就够（低 denoise 只走尾段日程，第 09 讲）。这条管线就是 WebUI 里 "Hires fix" 的节点化真身——在 ComfyUI 里它不是一个开关，而是你亲手搭的五个节点，**每个环节都可插拔**（比如第二段换个更擅长细节的 checkpoint——完全合法的玩法）。

### 管线 C · 分块放大（4K+ 的终点站）

目标 4K 时第二段 KSampler 的潜空间太大，16GB 显存吃紧且大画布易结构漂移。方案：**切块分治**——把图切成带重叠的瓦片，逐块低 denoise 重绘再缝合（Tiled Diffusion / Ultimate SD Upscale 类扩展节点，第 15 讲装）。displaystyle 显存只承担单块成本，任意目标分辨率。注意：分块时每块看不见全图，denoise 必须更低（≤0.35）且提示词只留质量词，否则每块各画各的。

## 2. 自动修脸修手：Detailer

远景人物的脸在 1024 直出里只占几十像素——潜空间 8× 压缩下必然崩（第 04 讲的账）。手工流程是第 09 讲的"圈脸 inpaint"，而 **Impact Pack** 扩展的 FaceDetailer 节点把它自动化：

```text
成图 ─▶ 检测器(自动找脸/手, YOLO 系小模型) ─▶ 对每处: 裁出 ─ 放大 ─
     低 denoise 重绘(0.4 左右) ─ 缩回贴合 ─▶ 输出
```

本质是"批量自动化的局部 hires"——检测、裁块、重绘、回贴，全是你已学过的部件。动漫脸要在检测器里选 anime 专版模型。装好后它通常是**每条出图管线的最后一站**。

## 3. 完整出货管线（本课程实战部分的合订本）

把 07–14 讲串成一条"从想法到 4K 成品"的完整流水线——也是你朋友那类复杂工作流的全部骨架：

```text
[生成] Illustrious 底模 + LoRA(11) + openpose ControlNet(12) + IP-Adapter(13)
        └ 1024 直出, 固定种子扫参数(08) → 选中意的一张
[修补] inpaint 精修穿帮处(09) → FaceDetailer 自动修脸(14)
[放大] hires 两段式 2×(14-B) → 需要 4K 再上分块(14-C)
[出货] Save Image → E:\AI\Outputs
```

按第 07 讲的骨架读法自查一遍：粉线主动脉几进几出、每个外挂挂在哪条线上——能在脑中画出这张图，本课程的实战目标就达成了。

## 上机任务

2. 管线 B 第二段 denoise 扫 0.3 / 0.45 / 0.6，找到你的审美甜点，并亲眼确认 0.6 时的结构漂移；
3. （装好 Impact Pack 后）给一张多人远景图跑 FaceDetailer，前后对比每张脸。
