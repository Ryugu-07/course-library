# 第 08 讲 · 参数手册：钉死变量再调参

> 一页速查 + 一套方法。每个参数的"是什么"在上篇都推导过了，本讲给的是"怎么定值"：默认值、甜区、什么症状该动哪个旋钮。核心方法论只有一句——**固定种子，一次只动一个参数**——这是把生图从抽卡变成实验科学的全部秘密。

## 1. KSampler 参数速查表

| 参数 | 默认起点（SDXL） | 甜区 | 症状 → 动它 |
|---|---|---|---|
| `seed` | 随便，但**调参时必须 fixed** | — | 复现/对比的锚点 |
| `steps` | 25 | 20–35 | 图"没长完"（噪点、结构虚）→ 加；纯粹想快 → 减到 20 |
| `cfg` | 6 | 5–7（SD1.5: 7–9） | 不听提示词 → 加 1–2；过饱和发焦、肢体崩 → 减 |
| `sampler` | `dpmpp_2m` | 见第 03 讲表 | 要多样性/质感换 sde 或 ancestral 系 |
| `scheduler` | `karras` | karras/normal | 一般不动；换模型家族才查推荐 |
| `denoise` | 文生图 1.0 | 图生图 0.2–0.7 | 第 09 讲的主角 |

## 2. 分辨率：不是想填多少填多少

**铁律：贴着模型的训练分辨率用**（第 04 讲系谱表）。SDXL 训练在 1024² 总像素附近的一组桶上，SD1.5 在 512²。偏离太远的直接后果：

- **太大**（如用 SD1.5 直出 1024）：**复影/双头**——U-Net 的感受野按训练尺寸校准，画布大了它会"把构图画两遍"。想要大图走第 14 讲的放大流水线，不硬撑直出；
- **太小**：细节挤压、质量下降。

SDXL 常用尺寸桶（总像素≈1M，都能整除 64）：

```text
1024×1024 (1:1)   832×1216 / 1216×832 (2:3 竖/横, 人像常用)
896×1152 / 1152×896 (3:4)   768×1344 / 1344×768 (9:16)
```

`batch_size`：一次并行几张（显存线性上涨）。探索期 batch=4 快速撒网，定稿期 batch=1 精修。

## 3. 提示词：SDXL 的写法

第 04 讲讲过：SDXL 是双 CLIP 编码器，吃"关键词堆"也吃短句。结构模板（和姊妹课程第 16 讲同源）：

```text
[主体与细节], [动作/情境], [环境], [构图/视角], [光线], [风格/媒介], [质量词]
```

四条实用规则：

1. **越靠前权重越高**，主体放最前；
2. **权重语法**：`(word:1.2)` 加权、`(word:0.8)` 降权——机制是缩放该 token 的嵌入向量，1.1–1.3 是常用区间，超过 1.5 容易画面畸变；
3. **负面提示写"缺陷类别"**而不是抒情：`low quality, blurry, bad anatomy, extra fingers, watermark, text`（动漫模型另有约定，第 10 讲）；它是 CFG 的"被推离参照物"（第 03 讲），认真写但不必堆砌；
4. **77 token 限制**：超长提示词会被分段编码再拼接，靠后的内容影响力衰减——写重点，别写作文（FLUX/T5 系才吃长文，第 04 讲）。

## 4. 系统调参法：症状 → 旋钮

拿到一张不满意的图，按这个决策序处理（每步固定其他一切变量）：

```text
1. 构图/内容不对        → 改提示词, 或换 seed 重抽(构图由种子+提示共同决定)
2. 内容对但不听细节指令  → cfg +1~2;  仍不行 → 提示词加权重语法
3. 结构对但质感糙/没长完 → steps +5~10;  或换 dpmpp_2m_sde
4. 过饱和/发焦/肢体崩    → cfg -1~2
5. 反复调都差口气        → 问题多半在模型: 该换 checkpoint 了(第 10 讲)
```

**记录你的配方**：每当调出满意的组合，把 PNG 存好（工作流在元数据里，第 07 讲）+ 在笔记里记一行"场景 → checkpoint + 关键参数"。三个月后你会拥有自己的参数库——这比收藏一百个别人的工作流有用。

## 5. 快速迭代的工程习惯

- **粗探索用小配置**：探索构图阶段 steps=15、batch=4、甚至先用 SD1.5 跑小图——把"每次尝试的成本"压到几秒，满意再换 SDXL 精修。这是姊妹课程"编排思维"的生图版：**先便宜后昂贵**；
- **对比看图**：Outputs 里按时间排序对比；或在画布上放多个 Preview Image 节点并行看；
- **别迷信"万能负面提示串"**：网上流传的三百字负面咒语大多是古早 SD1.5 时代的货物崇拜，对 SDXL 常无益甚至有害。从短列表开始，缺什么补什么。
