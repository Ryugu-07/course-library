## 阅读方式

每个核心页现在都有两种可切换的读法。**学习模式**要求先预测一次状态、轨迹或性能结果，再运行页面内的最小模型，最后进入真实 Lab 或 Project；**速查模式**收起学习层，只保留原有定义、算法、代码和工程结论。页面实验负责建立直觉，`labs/` 中的可运行代码与大 Project 才负责真正实现，两者不会互相替代。

## 0. 这一站和数学、物理站的本质区别

数学与物理的知识主体在推导里；**计算机的知识一半在讲义里，另一半在键盘上**。OS 课的灵魂不是调度算法的伪码，是你自己写的页表跑通的那一刻。所以本站是**讲义 + 实验双轨**：

- **讲义**：52 页全量成稿，覆盖原理到工程细节，体例沿用 grad-math/physics 的**三级标注**——【推导】全程给出、【骨架】关键步骤、【引用】结论 + 出处；每页头部**对标公开课程**（CS170 / CSAPP / 6.S081 / 15-445 / 6.824 / CS143 / 15-418 / 6.172 …——这些是全世界公认的黄金课，讲义帮你把它们的主干接到你已有的数学地基上）。
- **实验**：分两类，见[实验总表](labs.html)。**★ 本站已写**——`labs/` 目录下可直接运行的小实验（Mac 为主，CUDA 系列在 Win 4060 Ti 上跑）；**📋 大 project**——第二档课程作业（xv6 全套、从零数据库、分布式 KV 等，都是数月工程），本站给出教师版说明书：目标、阶段、接口、测试、评分与延伸挑战，实现留给学习者分阶段完成。

## 1. 你的坐标（为什么这样排课）

你已有：408 概念框架、CS61A（程序抽象）、应用数学全套（本站的理论线对你是**降维打击**——图灵机是自动机上的算子、随机化算法是概率线变现、LP 对偶你在优化线证过）。你缺的：**系统层的肌肉记忆**——所以系统线是本站主体（18 页），且每页都指向动手。

## 3. 阅读顺序建议

- **按线读**（默认）：每条线内部是严格递进的。
- **快速路径**（想尽快看到全景）：algo-01 → toc-01 → csapp-01/02 → os-01 → net-01 → db-01 → dist-02 → perf-01 → gpu-01 → web-01。十页走完，计算机的"骨架感"就有了。
- **理论线可以倍速**：你的数学底子让这 9 页更像"换个记号复习"；系统线请慢读 + 动手。
