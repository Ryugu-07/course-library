# L11 Rust 所有权谜题集

`compile_fail/` 保存四段“应该被借用检查器拒绝”的最小程序；`src/lib.rs` 给出对应的
惯用修法并用单元测试固定行为。

```bash
make test
```

安装 Rust 后，验收脚本会逐个确认错误样例确实编译失败，再运行 `cargo test`。当前机器
没有 Rust 时只做文件结构检查并明确报告跳过，绝不会伪装成编译通过。

建议顺序：先只读错误代码并预测诊断，再运行 `rustc`，最后看修正版。扩展任务：分别用
`Rc<RefCell<T>>` 和消息传递解决一个共享可变状态问题，比较运行时与编译期保证。
